# V2.1 比赛真实性基准

引擎代号：`V2.1`

基准版本：`v2.1-realism-v2`

本基准用于校准稳定的 V2.1，不用于推进 V2.5，也不表示精确复刻某一个联赛或赛季。目标区间采用职业及顶级联赛的宽区间，避免引擎为了贴合单一数据集而过拟合。

## 判定规则

- 正式判定至少需要 10,000 场；当前联赛真实性矩阵为 385 个正常场景 × 26 次重复，共 10,010 场。
- 双方生态强度独立按配置权重抽取；天气和裁判按引擎真实权重抽取。
- 极端阵型压力套件保留在配置中但不参与正式真实性判定。
- 加权指标通过率至少为 80%。
- 任一关键指标越界，结论为 `review`；没有关键失败且样本、通过率都达标时才为 `pass`。
- `low` 和 `high` 分别表示低于或高于目标区间，`missing` 表示汇总结果缺少该数据。

关键指标覆盖：每场进球、每场 xG、进球/xG、射门、射正、射正率、主胜、平局、0-0、平均控球差、xG 分桶校准误差。

诊断指标覆盖：客胜、BTTS、零封、比分差尾部、角球、越位、扑救、封堵、纪律、防守动作、定位球射门、进球部位和控球优势分布。

方向性对比还会验证：耐心控球对直接长传的控球优势、控球打法对反击打法的控球优势、全攻对摆大巴的射门优势，以及全攻相对摆大巴付出的失球代价。

所有具体上下限都保存在 `engine-comparison-v2.1-full-realism-baseline.json` 的 `realismBenchmarks.metrics`，结果 JSON 会在 `realismBenchmark` 中逐项给出数值、区间、状态及关键失败列表。

## 分析顺序

1. 先看 `realismBenchmark.verdict`、样本是否达标、关键失败和加权通过率。
2. 再看进球、xG、射门、射正因果链以及 `xgCalibration`，确认高 xG 与进球偏差是随机波动还是结构性失准。
3. 检查比分分布及大比分尾部，避免只靠均值掩盖异常比赛。
4. 检查控球差、60%/70% 控球比赛占比，确认打法能够拉开控球而非回归 50-50。
5. 检查抢断、拦截、解围、封堵、压迫成功和定位球产出。
6. 最后按阵型、战术、细节策略、极端阵型、天气和裁判维度定位异常来源。

调整引擎后应使用同一配置和固定种子复跑，只有需要修改真实性定义时才提升基准版本并记录区间变化。
