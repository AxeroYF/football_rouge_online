# Sponsor icon staging

These files are staged assets only. No sponsor model, gameplay rule, page, stylesheet, or runtime import references this directory yet.

## Sources

- Apple, Emirates, Nike, Adidas, Samsung, and Sony: Simple Icons CDN. Simple Icons source code is CC0-1.0; brand names and logos remain trademarks of their owners.
- Microsoft: Wikimedia Commons `Microsoft logo (2012).svg`.
- Mizuno: Wikimedia Commons `MIZUNO logo.svg`.
- Jissbon: official `jissbon.com` website asset `theme/img/logo-black2.png`. The similarly named `.com.cn` domain is parked and was not used.
- 主任株式会社: user-provided `icon-yf-v1.ico`; preserved as ICO and converted to a 256×256 RGBA PNG for web use.

## Integration status

`sponsors-manifest.json` is an inventory only. It is not loaded by the game.
