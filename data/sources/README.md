# S4 player data sources

## EAFC26 Player Database

- Source: https://www.kaggle.com/datasets/flynn28/eafc26-player-database
- Dataset update: 2025-11-24
- Retrieved: 2026-07-26
- License: GPL-3.0
- Official rating reference: https://www.ea.com/games/ea-sports-fc/ratings
- Local archive: `eafc26-player-database-20251124.zip`
- Male player source: `eafc26-player-database-20251124/EAFC26-Men.csv`

The source contains the EA FC 26 reference overall, primary position,
alternative positions, nationality, club, league, height, preferred foot,
six headline attributes and detailed outfield/goalkeeper attributes.

The S4 candidate database keeps reference ratings separate from proposed
YellowDogs League ratings. External ratings must not overwrite game balance
without review.
