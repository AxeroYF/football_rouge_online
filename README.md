# Two-Continent Campaign Hub

欧洲与南美洲征程地图大厅原型。南美洲采用缩放后的并列布局，放置在欧洲右侧；支持国家、省州、城市和俱乐部视图，俱乐部徽章来自项目内的 S4 备份。

```powershell
npm run dev
```

打开 `http://127.0.0.1:4370/`。

## Data credits

- Country boundaries: Natural Earth, `ne_50m_admin_0_countries`
- Province/state boundaries: Natural Earth, `ne_10m_admin_1_states_provinces`
- Map interaction: Leaflet 1.9.4
- Club badges: local YellowDogs League S4 backup
