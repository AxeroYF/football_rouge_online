## 当前权威结论

- 界面维持项目原来的深色主题；浅色主题实验已被用户否决并回退。
- 地图本体不因主题实验改色，领土颜色也已恢复原方案。
- 玩家池不存在私有池/公共池所有权限制，所有玩家均可获得所有球员。
- 球员卡包只有四种：传奇、珍奇、稀有、普通。
- 中立地块征服奖励统一发放珍奇球员卡包；旧存档的新地块征服包会迁移为珍奇包。
- 球员编队只有远征与留守两种。所有非远征球员自动属于留守，不存在未编队状态。
- 战术板有两个固定且不可删除的方案：远征、留守；两套首发和替补不能共用球员。
- 远征战棋决定进攻起点，并已支持在己方领土间耗时移动和中止。
- 背包使用既定“小型窗口”标准；开包三选一使用全屏流星雨舞台，不再套额外窗口。
- 新功能 UI 避免无意义英文标题、说明性小字和冗余按钮。
- 浏览器端体验测试由用户自行执行，Codex 负责静态检查和自动化测试。
