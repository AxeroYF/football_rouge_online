# 手机浏览器地图入口修复 · 2026-09-30

基线为已部署、已提交的 R45（c9daf07）。本项已打包为 R46，用户已确认部署；包和指令见 [R46 更新说明](R46_UPDATE_20260930.md)。

## 原因与实现

- 联赛、服务器玩家、通知栏分别维护 fixed 坐标。横屏规则把联赛和通知栏同时放在 right:220px；竖屏玩家栏和通知栏同时占据右上方，层级覆盖导致入口看不到或点不到。
- 新 styles/map-hud.css 统一窄屏及短屏入口的位置、宽度和顶部高度。三个入口各占一列；540px 以下标题和按钮分行。展开的玩家及通知内容在标题下方使用独立宽面板和滚动区，始终保留入口的点击空间。安全区内缩兼容刘海横屏。
- 1280px 统一走紧凑布局，宽屏联赛抽屉从 1281px 开始，避免边界处混用抽屉和紧凑标题。
- 横屏互斥展开逻辑改为读取当前玩家栏按钮状态。原按钮会在玩家栏重绘时被替换，读取已脱离页面的按钮会误收起刚展开的通知。
- 更新 index.html 资源内容版本，无服务端修改或新增轮询。
