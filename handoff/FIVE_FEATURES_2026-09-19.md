# 交易筛选、联军踢出、属性解限、研究按钮与俱乐部筛选

状态：本地修改和验证完成；遵守用户要求，未打包、未部署。通过本地 PowerShell 7 执行。

## 功能

1. 玩家交易双方仓库与卡片市场明确展示“强化等级”筛选标签，支持未强化、+1～+8、全部等级；双方筛选独立，重置还原。复用已有等级筛选，不新增重复控件。市场将旧卡缺失 upgradeLevel 按 0 处理。
2. 普通联军、豪门活动联军允许指挥官踢出其他玩家提供的借调球员。请求同时指定原玩家与原卡片，服务端校验指挥官权限、联军身份和版本；原卡留在原玩家仓库，不转让、不销毁。普通联军行军/出征/比赛中、活动联军比赛中，先标记待归队，忙碌结束后释放。归还保留个人编队安排，并清除失效的联军阵容与目标提案。原玩家自行归队规则保留。事务保存失败恢复借调标记和联军名单。
3. 单项属性开放 99 上限，存储/卡面保留真实值。线上 V2.1 在比赛属性入口统一使用：x <= 99 时为 x；x > 99 时为 99 + (x - 99) × 0.2。示例：100→99.2，109→101，199→119。训练、强化、新抽到强化卡、特性、羁绊、schema 标准化和成长迁移不再提前裁掉超额部分。比赛快照保留 displayAttributes 原值；概率/事件/点球使用折算后的属性，快照复用不重复折算。该规则适用于双方，包括豪门球队；既有总评公式、特性触发和概率边界未另行调整。
4. 研究通用按钮的可操作样式修复：启用时高亮且 cursor:pointer，实际禁用时显示禁用样式。此前只有阵型研究覆盖默认灰色/not-allowed 样式，强化与生物学研究误显示为不可用。未放宽服务端研究条件。
5. 编队新增俱乐部筛选，选项来自当前完整代表球员仓库，可与国家、位置、强化等级等交叉筛选，继续保留滚动与行节点复用。

## 旧存档与兼容

有原始属性、已保存的强化基值或训练累计值的卡，加载时可恢复之前在 99 被裁切的已知成长。重复加载不会重复加点。旧训练已退款/未记录的成长不会额外补发，历史比赛和结算记录不重算。离线实验环境的显式模式开关保持兼容；线上默认不需要新增环境变量，固定采用 20% 超额折算。
