## 坐标原则

- 高程数据始终从真实地理坐标读取，不能拿南美洲的展示坐标直接请求 Terrarium。
- 南美洲运行时变换为：
  - `displayLat = 7 + (sourceLng + 57.5)`
  - `displayLng = 20 + (sourceLat + 21.5)`
- 该变换交换了经纬轴。构建展示瓦片时必须逐像素从展示坐标反算源坐标，先把高程重采样到展示网格，再计算坡度和山体阴影；否则山脉方向和光照都会错误。
- 南美可见展示范围暂定为经度 -15 至 58、纬度 -20 至 36，对应源范围经度 -84.5 至 -28.5、纬度 -56.5 至 16.5。
- 这一范围有意遵守当前地图南纬 -20 的裁切，会排除变换后在画布外的加拉帕戈斯等离岛。规划脚本会明确列出完全落在范围外的地块。

## 斯瓦尔巴

- 现有地图数据已包含 `adm1:nor-901`（斯瓦尔巴），最高纬度约 80.77。
- 原欧洲 DEM 和地图北界只到 75，曾导致其大部分地形被裁掉。
- 独立地形范围规划为经度 7 至 36、纬度 74 至 82。
- 地形资源接入后，`CAMPAIGN_BOUNDS` 北界已从 75 调整为 82；欧洲运行时地形北界收至 74，避免与斯瓦尔巴独立层叠加。

## 构建产物

- 南美概览：`assets/map-relief/south-america-dem-overview/{z}/{x}/{y}.webp`
- 南美细节：`assets/map-relief/south-america-dem-z8/{z}/{x}/{y}.webp`
- 斯瓦尔巴概览：`assets/map-relief/svalbard-dem-overview/{z}/{x}/{y}.webp`
- 斯瓦尔巴细节：`assets/map-relief/svalbard-dem-z8/{z}/{x}/{y}.webp`

配置位于 `shared/config/map-relief-regions.json`。运行以下命令可检查源坐标、展示坐标、瓦片范围和被裁切地块：

```powershell
python scripts/map_relief_regions.py
```

重新生成区域地形：

```powershell
npm run build:relief-regions
```

构建器会按地块遮罩建立瓦片索引，只下载实际陆地区域需要的 Terrarium 源瓦片；透明海域仍写入极小的占位 WebP，避免 Leaflet 在矩形 bounds 内产生 404 请求。

只重新生成概览色调：

```powershell
python scripts/build-map-relief-regions.py --overview-only --region south-america
```

南美洲 z8/z9 细节采用亮度 1.24、对比度 1.20 与山体阴影对比度 1.40；概览层直接从校正后的 z8 向下派生，不再重复调色。斯瓦尔巴采用较温和的亮度/对比度 1.08，欧洲 z8/z9 也按统一高倍率基线重建。欧洲与南美洲的海岸描边和三层浅海带共用同一套坐标变换、Canvas renderer 与三级 LOD。

单独重建欧洲 z9 细节（保留现有 z8 作为上一层原生瓦片）：

```powershell
npm run build:relief-europe-detail
```
