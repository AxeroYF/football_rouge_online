# 强化界面修复 · 2026-09-05

用户要求恢复强化按钮旧样式、解决结果导致左上面板伸缩、左下记录支持滚动显示最近 50 条。

## 已实现

- styles/ui-theme.css 不再覆盖主强化按钮的形状、背景、字体和状态；原 styles/enhancement.css 的 90×90 圆形金色渐变、立体阴影、悬浮与禁用样式恢复。其余控件继续使用统一主题。

- 重渲染选卡/筛选时保留记录滚动位置；发现新的历史首条 ID 时自动显示顶部最新结果。
- index.html 的强化 CSS、主题 CSS、app.js 及 app.js 中强化控制器缓存版本更新为 20260905-enhancement-ui-v9。
