# Rougelite 累计热更新 · 20260912-r1

适用：已安装的阿里云正式服务 yellowdogs-rougelite，程序 /opt/yellowdogs-rougelite/app，数据 /var/lib/yellowdogs-rougelite，Node /opt/yellowdogs-rougelite/node/bin/node，端口 4380。

本包包含从 S4 羁绊增益显示调整，到强化研究、生物研究的累计程序与素材更新。基线为 2026-09-09 阿里云正式包，覆盖该基线之后的前端更新。它是需要短暂停服重启的累计更新，不是零停机替换。

## 包含更新

- 羁绊增益恢复 S4 展示逻辑：默认关闭、切换首发属性预览、最多两项实际增益、所有满足条件的羁绊摘要常显。
- 友谊后可结盟，联盟共同响应宣战；盟友共享迷雾、通行、球探发掘及体能设施，借地征服可申请持续授权并撤销。
- 恢复中心覆盖范围随等级扩大，点击设施直接显示；设施升级显示当前值 → 升级值。
- 球探进入中立地探索、可见范围内显示其他玩家队伍、玩家颜色区分队伍；服务器列表仅包含已建队玩家，世界事件通知完善，隐藏无权查看的施工进度。
- 球探中心升级不再抬高单轮发掘价格，支持最多 20 轮连续队列、每轮选一并统一领取。
- 修复 5 合 1 汰换预览的函数克隆报错；优化三选一卡片界面加载。
- 工厂与大学及各级模型，地形／邻接产出与选址预览，拆除功能和队伍标记调整。
- 球员工资及设施养护按用户确认的基础方案减半版本执行。
- 60 处可争夺石油地块，58 处大陆、2 处大型岛屿；排除中立豪门地块。单等级油井每小时产油 3，油桶图标、地形油斑和资源收支浮窗，支持市场交易及盟友赠送。
- 石油按整小时结算、库存整数显示；工厂耗油 1/小时，供油正常时产出 +20%，断供停止加成；缺油移动变慢，移动确认文案简化。
- 高倍率设施尺寸渐进缩小，最高倍率约缩小 15%。
- 强化研究：每种有效主卡／材料组合独立 10 级，每级成功率 +0.5 个百分点，最高 +5 个百分点，最终概率不超过 100%。
- 生物研究：5 级比赛耐力，远征队球员比赛体能消耗依次减少 3%、6%、9%、12%、15%。与阵型共用单一队列，按科技值推进、离线结算、进度保存及右侧通知。

## 上传与更新

把 tar.gz 和同名 .sha256 一起上传到 /home/admin，保留解压目录用于回滚。建议先让正在比赛的玩家结束比赛，再执行。不要运行首次安装器，不要导入 S4 账号种子。

```bash
cd /home/admin && \
sha256sum -c yellowdogs-hot-update-20260912-r1.tar.gz.sha256 && \
tar -xzf yellowdogs-hot-update-20260912-r1.tar.gz && \
sudo bash yellowdogs-hot-update-20260912-r1/update.sh --check && \
sudo bash yellowdogs-hot-update-20260912-r1/update.sh apply
```

`--check` 只读校验包、现有服务目录、存档及依赖，不停服。`apply` 会获取更新锁、停止服务、备份受更新影响的旧文件和完整数据目录、覆盖程序、启动并检查本机健康与游戏页面。新版本启动检查失败时自动恢复配套旧程序与更新前数据，并重新启动。

程序不会覆盖 /etc/yellowdogs-rougelite.env、Nginx、证书、Node、后台球员目录、球员头像和图鉴文件；不会重置建队或重新导入账号。新增经济机制依照当前程序初始化，建队账号首次获得 30 石油，工资养护不追扣更新前时间。

备份位于 /var/backups/yellowdogs-rougelite/hot-updates/20260912-r1-时间戳。实际路径和回滚命令会在终端打印。备份包含私有存档，只保存在服务器私人目录；请另行下载妥善保存。备份空间不足或校验失败时先排查报错，不要删除线上存档来继续。

## 回滚

使用安装完成时打印的实际备份目录：

```bash
sudo bash /home/admin/yellowdogs-hot-update-20260912-r1/update.sh rollback /var/backups/yellowdogs-rougelite/hot-updates/20260912-r1-实际时间戳
```

回滚恢复配套旧程序和更新前存档，因此更新后产生的进度不会留在回滚后的游戏中。回滚前的较新数据会保存在 /var/lib/yellowdogs-rougelite.before-rollback-时间戳，供排查或后续恢复，不会直接删除。不要在恢复正常运营数日后随意回滚存档。

安装被人为中断、机器掉电时保留备份和解压包，检查服务状态及备份 BACKUP.json 的 ready 标志。确认没有另一更新进程后，才处理残留 .hot-update-lock；不要盲目反复覆盖程序。
