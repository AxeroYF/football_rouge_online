# 合并地块后的地图对象放大 · 2026-09-09

**后续修正：** 本文最初采用的单位固定下移与全局侧向展开已被 [边界约束布局](UNIT_TERRITORY_ANCHOR_FIX_2026-09-09.md) 替代；近景放大保留，拥挤地块可自动收紧单位尺寸。

用户要求：合并后地块面积变大，高放大倍率下设施、远征队、球探太小，需要放大。已完成前端显示调整。

- 采用当前实际使用的 Leaflet 模型图标路径；没有修改未使用的 `CampaignFacilities` 三维建筑路径。
- zoom ≤ 5.8 时保留原尺寸；5.8 至当前最高 zoom `3 + log2(30)` 平滑增加，最高宽高为原来的 1.65 倍。最高倍率设施图标宽度约 94 → 154 像素；远征队 76×80 → 125×132；球探 64×82 → 106×135。
- 保留原来的低倍率缩小逻辑。远征和球探的图片、点击框与锚点同步缩放，连续缩放复用 DOM，不反复重建图标。
- 近景将单位显示行与建筑行错开，保持地图真实坐标和移动路线数据不变。四名球探分配独立侧向位置，解决原先第 1/3、第 2/4 名重叠问题。
- 所有设施共用此规则，包括总部、球场及奇观图标。地块尺寸、单位能力、移动耗时和存档均不改变。

主要文件：`shared/map/object-display-scale.mjs`、`client/buildings/building-marker-controller.js`、`client/map/expedition-piece-controller.js`、`client/map/scout-unit-controller.js`，以及 `app.js`/`index.html` 缓存版本。
