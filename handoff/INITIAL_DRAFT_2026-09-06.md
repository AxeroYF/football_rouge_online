# 初始选人四池流程 · 2026-09-06

版本标记：`20260906-draft-v3`。以本文件的 v3 规则为准；此前“每个具体位置各 3 人”和星际穿越背景已替换。

## 当前选人规则

新建队总共选择 **33 名球员，仅门将 GK 至少 3 人**。其他具体位置没有最低人数或 3 人上限，门将超过 3 人也可继续选择。

| 球员包 | 具体位置 | 人数限制 |
| --- | --- | --- |
| 门将 | GK | 至少 3 人，可多选 |
| 后场 | LB、CB、RB | 自由选择 |
| 中场 | LM、RM、AM、DM | 自由选择 |
| 前场 | LW、ST、RW | 自由选择 |

四个池子由玩家自行打开。每次出现最多三张候选，选择一名后回到池子入口。当剩余总名额等于尚缺的门将人数时，只开放门将包，为补齐门将预留名额。例如前 30 人都不是门将，最后 3 次只开门将包；已有 2 名门将时，最后 1 次必须补门将。服务端开包、提交选人均校验这一条件。

界面不展示各位置 `0/3` 等配额。统计分四组：上方显示“门将／后场／中场／前场”的总人数，下方显示各具体位置实际人数，例如前场 5，下面 LW 2、ST 2、RW 1。保留顶部整体人数进度，不添加说明小字；暂时不能开的池子按钮使用必要短状态“先选门将”。

## 候选与概率

候选评级权重保持 C 30%、B 40%、A 25%、S 5%，集中在 `shared/config/draft.mjs`。这是单张候选的生成权重，玩家主动选择后的最终阵容比例不等于这些权重。某具体位置某评级没有剩余候选时，在该位置的可用评级间重新分配权重，不跨池补卡。X 及未发布卡不参与。

- 同一次开包优先展示不同具体位置，后场通常为 LB / CB / RB，前场通常为 LW / ST / RW。
- 中场根据历史候选次数轮换 LM / RM / AM / DM，避免某位置长期不出现。
- 均衡的是候选展示次数，不限制玩家选择次数；已选超过 3 人的位置仍会出现在候选中。
- 候选内及已选阵容内不重复球员 ID。已打开的候选持久保存，刷新、重试不会重新随机；当前候选未选完时不能改开其他池子。

## 背景与翻牌

初始选人已移除星际穿越 Canvas 接入，复用现有 `client/ui/meteor-background.js` 的 48 道流星及成熟动画路径。蓝色背景、蓝白流星仅作用于初始选人，背包开卡原有配色不受影响。背景与选人内容分开挂载，换轮不重建流星；标签页隐藏时暂停动画，退出选人时移除背景和事件监听。

三张候选继续使用现有静态盾形卡，翻牌由独立外层完成：

1. 提前加载并异步解码卡面图片，最多等待 350 毫秒，图片失效或一直加载也不会卡住流程。
2. 每张翻牌 420 毫秒，依次错开 45 毫秒，仅外层执行旋转。翻牌过程中临时启用合成层提示，完成后清理。
3. 只在候选实际变化时重建卡片。请求提交、响应后的收尾、错误提示及同一候选的刷新只更新按钮状态，保留原卡片 DOM、图片和动画进度，修复原先重复重建造成的闪烁和动画重启。
4. 翻牌完成前禁止重复选卡；最后一张结束后开放选择，另有超时兜底。关闭页面或换轮会取消计时器、动画帧与监听，晚到回调不会影响新页面。
5. 系统要求减少动态效果时，跳过翻牌旋转。

四池页面仍使用已有卡包素材及项目面板样式。桌面统计为四组一排，窄屏改两组一排；手机候选按两列加底部居中一张展示。

## 服务端与旧进度

核心逻辑位于 `server/application/draft-service.mjs`，由 CampaignService 接入：

- `POST /api/campaign/draft/open` 接收 `pool` 与 `pickNumber`。
- `POST /api/campaign/draft/choose` 接收 `playerId` 与 `offerId`，只接受当前账号保存的候选；最近一次相同选人请求幂等返回，过期提交被拒绝。
- 开包、选人、规则迁移与最终完成在保存失败时还原内存状态。客户端响应丢失时读取服务器状态恢复，销毁后的晚到响应被忽略。
- 已完成建队账号保持现状，不重新选人。
- 未完成旧进度读取状态时迁移至 v3，保留已选球员。v2 已打开且符合新规则的候选原样保留；不符合门将预留条件的旧候选清除后补开门将。
- 原 v2 因某位置超过 3 人而增加的总名额会按新规则校正。例如已选 5 名 GK 的旧进度仍以 33 人完成，不再要求 35 人。
- 若旧进度已经超过 33 人，不删除已选卡；只补必要的门将。例：旧进度已有 33 人但没有 GK，保留全部已选卡并补 3 名 GK。已满足人数与门将要求的旧进度直接完成，避免界面没有可用按钮。这仅是旧存档兼容，新建队严格为 33 人。
