适配器接受现有 `createV2Match` 使用的两队席位，读取球员实际 ID、已强化属性、初始体力、位置、阵型预设、职责、开局/领先/落后计划和研究等级。深拷贝后使用，不回写账号、不重复强化。

真实复用的 V2.1 模块：战术分维度/细节解析、阵型角色推断、动态阶段阵型、职责移动修正、球员特性属性/羁绊/附近化学加成、超 99 属性折算、位置适配、传球和射门阵型研究修正。球员条件属性每 5 秒按比分、分钟重新计算；形状每 0.5 秒重新计算。

混合方式：V2.1 生成阵型与职责目标，V2.2 用有速度/加速度限制的运动执行；接球、截球需要满足实际位置/球路条件。进攻球员会控制越位线并寻找接应位置；防守由最近一到两人压迫，其余保持阵型保护。随机种子固定，模拟结果不依赖渲染帧率。

这不是“V2.1 全部数值结果的动画皮肤”。新空间过程产生新比分，不保证与 V2.1 同种子结果相等。当前不执行全部特性事件钩子、队长事件修正、天气影响、疲劳累积、换人、伤病、点球大战与正式比赛经济结算。

## 足球规则

以 IFAB 2026/27 为依据实现可测试的规则子集：

- 出脚时保存球、接球队员和倒数第二名对手位置；同线、本方半场、球后方不越位。站在越位位置本身不吹罚。
- 触球参与时确认越位；明显越位立即判对方间接任意球，接近判线的进攻延迟举旗。1 米是演示的延迟举旗策略阈值，不是允许越位的容差；最终仍按实际位置判断。
- 球门球、界外球、角球直接接球免越位；间接任意球不豁免。
- 进球暂不记分，VAR 回看保存的出脚快照；有本次进攻越位证据则取消，否则确认一次。没有随机“黑哨/取消进球”概率。
- 球整体越线后，依据最后触球队伍判界外球、角球或球门球；进球才回到中圈开球。死球等待省略后切换到合法类型的重开球位置，第一脚传出，避免开球者直接连续触球。
- VAR 画面有明确的出脚定格提示与参考线，不把回看画面当作现场球员瞬移。

当前以球员可触球身体位置的单点近似判线，不具有真实人体轮廓精度。规则函数预留挑战/遮挡参与种类，比赛过程目前自动检测触球参与；挡住门将视线、争顶干扰、扑救反弹后的所有越位分支、门柱弹射、手球、犯规/红黄牌/点球、半场换边、补时等还未完整实现。球出界的重开球类型可执行，但当前常规传球策略优先留在场内，角球/界外球的自然出现率尚未校准。不能宣称完整 IFAB 裁判系统。

## 验证与结论

- 新增 10 项测试覆盖：原席位输入/不变性/强化属性不重复、帧率无关、时钟解耦、战术切换不瞬移、完整 600 秒坐标及速度/加速度边界；越位同线/方向/时点/豁免；边界归属；VAR 确认及取消。
- 原 R43 20 场整场结果/回放等价性和输入指纹，共 21 项回归通过。
- 20 个随机种子完整比赛抽样，无非有限坐标，无整场零射门。每场 600 秒的纯模拟在本机 Node 中约 331–424 ms，总进球 1–7；这是本机离线吞吐测量，不是线上并发或低配手机帧率承诺，比分分布仍需校准。
- 实际浏览器验证包含自然播放、暂停、战术切换、球员点选、进球 VAR、390px 手机/768px iPad/780px 横屏无横向溢出。初始化完成后播放不发起数据轮询请求。

值得继续小范围验证，暂不替换正式引擎。下一阶段优先补全犯规与点球/红黄牌、越位干扰/扑救反弹、门将及身体碰撞，再做战术统计回归和真实低配设备测试。接入线上时由服务端或可信工作线程生成权威比赛事件/快照，同一场复用一份缓存；客户端仅呈现和插值，不能上报并决定正式比分。演示的本地计算优势不能直接当成线上防作弊方案。

## 阵型跟进与防守收拢修订

根据实际演示反馈，原先开局站位的小幅平移导致后场参与不足，边路防守仍然铺满全场。新增 `team-block.js`，保留 V2.1 各位置/职责的相对几何关系，将其重新布置到随球位变化的整体阵型范围内：

- 持球推进时中卫与后腰跟进，同时保留球后保护；允许近侧进攻型边后卫参与接应。
- 选择两名合适的中场/边后卫形成近侧三角接应和后方回传点，留守边卫、防守锚点及中卫不被拉去追球。
- 防守时缩短纵向距离、收窄横向宽度，整体向有球侧偏移，远侧球员进一步内收。
- 压迫一至两人，其余球员保持整体保护；第二名压迫球员站在靠本方球门的一侧保护身后。
- 门将随防线适度跟进。原有 20 Hz 运动限制、2 Hz 目标更新、越位和 VAR 流程保留。

固定两队、固定战术、固定球位的目标站位对比（单位米，非整场统计）：

| 场景/指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 球位距本方底线 85m：进攻后卫平均深度 | 40.3 | 54.2 |
| 同球位：进攻中场平均深度 | 61.4 | 68.3 |
| 同球位：防守队横向跨度 | 53.3 | 33.1 |
| 球位移至边路 y=10m：防守队横向重心 | 34.0 | 21.1 |

新增三项阵型行为回归，与已有规则/运动测试共 13 项通过。12 个新种子完整 600 秒抽样：无异常坐标、无整场零射门，本机纯模拟约 370–484ms/场。进球分布仍未做正式平衡验收。实际桌面、iPad、移动端和横屏截图及录屏已重新生成。

## 再次增加前压与战术滑块接入审计

前场持球时增加 3–6 米的跟进修正，并恢复整体进攻心态对阵型纵向重心的直接影响。固定球位 x=85m 的同场景中，后卫平均目标深度由 54.2m 增至 60.7m，中场由 68.3m 增至 69.6m；中卫/锚点保护和越位约束继续生效，实际跑动不加速。

正式战术界面为 8 个滑块；`mentality` 是总体心态派生的第 9 个引擎维度。审计发现并修复：

1. 适配器构建默认开局预案后再次展开 `tacticalPlans`，可能覆盖球队级维度的回退值；现按球队配置、开局预案、细节修正顺序合并，逐值与 V2.1 解析结果对照。
2. `timeWasting` 曾只进入数据，没有参与动态决策；现影响低压下持球思考时间、安全传球倾向和死球等待，领先时更明显，受紧逼时不强行拖慢。
3. `counterAttack` 原先主要改变形状且接应存在档位跳变；现连续作用于夺回球权后 6 秒内的出球等待、纵向传球选择、前场跑位，随时间自然消退。重开球不会被误认作抢断反击。
4. 传球纵深由档位判断改为连续影响理想传球距离；比赛节奏也控制没有立即出球时的再次决策间隔。

| 滑块 | V2.2 实际作用 |
| --- | --- |
| 比赛节奏 | 接球后的决策等待、再次考虑出球的间隔；不放大移动速度 |
| 传球纵深 | 理想传球距离、向前传球权重 |
| 进攻宽度 | 有球阵型横向展开 |
| 防线高度 | 整体阵型纵向位置、防线前压程度 |
| 压迫强度 | 接近持球人的范围与参与压迫人数 |
| 阵型紧凑 | 整体纵向间距、防守横向宽度和有球侧聚焦 |
| 反击倾向 | 球权转换窗口内更快出球、纵向选择与前场跟进 |
| 比赛控制 | 低压控球、偏安全的传球和适度死球等待 |

## 战术板驱动与复杂进攻接入（本次修订）

用户明确滑块指战术板的赛前配置，因此移除比赛页的临时滑块编辑器；保留只读参数与演示方案切换。引擎程序化维度覆盖仅用于离线测试。演示的公开球员样本现按真实 `tactics.planSnapshots.__s4V2` 格式创建，先经过 `buildAccountMatchSeat`，再经 `prepareV22Match`，不读取真实玩家账号。正式比赛仍使用 V2.1，本次未部署或打包。

修复链路：
- 方案切换同时携带对应的阵型分线、站位、职责和战术参数。
- 按实际站位推导角色，再用 V2.1 校验职责，避免不适用的职责触发动态行为。
- 整体阵型跟球移动时保留战术板绝对纵深偏好；通用接应按球员原本所在侧选接应点，降低对自定义站位的覆盖。
- 职责协同先计算并标记，通用接应不再覆盖，最后统一施加无球越位站位限制；实际移动仍受原有速度/加速度约束。

| 战术板职责或配置 | 动态行为 |
| --- | --- |
| 套边边后卫 + 内切边锋 | 有至少两名指定后场保护球员时近侧外线插上，边锋进入肋部；远侧边后卫保留回防 |
| 套边边后卫 + 下底边锋 | 外线纵向错层跟进，减少两人挤在同一通道 |
| 内收边后卫 | 进入中场半空间接应，丢球后恢复防守队形 |
| 组织前腰 / 影子前锋 | 分别回接组织、从后排插入禁区 |
| 回撤前锋 / 突前前锋 / 支点前锋 | 分别回撤串联、压住防线等待直塞、中路支点接应 |
| 下底边锋 / 内切边锋 | 持球路线也分别保持边线或切向中路 |
| 传中增减 | 改变传中发起区域；减少传中时仍允许底线倒三角回传 |
| 远射增减、机会创造 | 使用真实 `increase/reduce/balanced` 值影响起脚距离，修复此前无效的 `often` 判断 |
| 左路 / 左肋 / 中路 / 右肋 / 右路 | 影响传球目标选择权重，坐标随主客方向镜像 |

八个战术板滑块仍由 V2.1 解析细节修正后传入动态引擎，其作用见上表。当前并非完整复刻所有 V2.1 事件：传中有真实弧线、落点和拦截，但尚无完整争顶/头球对抗模型；二过一组合、复杂盯人交接和所有个人特性触发仍需独立扩展。

本次整场抽样还定位到门将扑救后循环出球被近身前锋截下、重复射门的问题。增加禁区内门将手控球状态，手控球不能直接被抢断；从手中分球采用真实起始高度和弧线。队友回传和禁区外接球不进入该状态，未取消正常传球拦截。

验证：29 项测试通过，其中新增 10 项使用实际保存战术格式覆盖双方镜像跑位、职责协同、球员站位、自动方案切换、八个滑块、传中、远射、越位约束和门将持球。12 个新种子的 600 秒完整抽样全部结束，坐标有限；单队射门 2–13 次，总进球 1–4，本机纯模拟约 415–521ms/场（非低配服务器基准、非平衡性验收）。继续在客户端 20Hz 推进、2Hz 更新跑位目标，播放期间无新增服务器请求。

浏览器检查涵盖实际播放、暂停、示例方案、自然套边场景、VAR、桌面/iPad/手机/横屏。截图与报告位于 `outputs/v22-demo-review/`：`overlapping-run.png`、`inverted-fullback.png`、`desktop.png`、`mobile.png`、`browser-report.json`、`board-tactics-simulation.json`。截图为本地真实运行结果，演示方案包含“套边与内切”和“内收组织”。
