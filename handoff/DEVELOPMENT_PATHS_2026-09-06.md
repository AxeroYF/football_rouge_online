用户本轮强调：参考《文明 VI》的多种发展路径，通过地块建筑协同形成不同收益，并适合现有黄狗风云。本文细化 [战略扩展提案](CIV6_STRATEGY_EXPANSION_2026-09-06.md)，并作为该提案中“发展路线/建筑协作”的最新建议。所有分支、项目和等级安排仍待确认。

## 一、改造目标

把俱乐部的发展拆成五种可以混合投入的路线：

- 青训供给：擅长获得符合需求的球员。
- 竞技科研：擅长把已有球员培养成需要的样子。
- 商业经营：擅长积累资金与经营收入。
- 球迷文化：擅长建立地区合作，取得服务和活动资格。
- 远征开发：擅长远距离行动、探索与资源获取。

每条路线都应具有：独特建筑组合、独特可执行项目、主要收益、持续消耗、阶段目标，以及没有投资其他路线时的短板。

建筑组合形成能力，资源与位置改变组合价值，领袖强化偏好。玩家不必先选职业才能使用某类建筑；可以主修一种路线，再用部分土地补充另一种路线。

《文明 VI》具有多种胜利目标，区域位置也影响产出；它们提示本项目同时设计不同目标与不同实现手段。[官方手册：胜利与失败，146 页](https://downloads.2kgames.com/civilization/vi/manuals/eu/CIV_VI_25TH_ONLINE_MANUAL_ENG.pdf)、[官方手册：区域与建筑，98 页](https://downloads.2kgames.com/civilization/vi/manuals/eu/CIV_VI_25TH_ONLINE_MANUAL_AUS.pdf)。商业在此作为本项目的发展路线，不把它误写成《文明 VI》标准规则中的独立经济胜利。

本项目持续运行，当前先做个人/地区发展目标和相应服务权益。全服胜负、赛季结算及继承规则另行讨论，不由达成一项项目自动结束服务器。

## 二、现有条件与可利用的基础

| 当前事实 | 改造意义 |
| --- | --- |
| 七类设施：主体育场、球探、训练、商店、医疗、恢复、港口 | 第一轮可用这些设施验证路线，无需先增加大量建筑类型 |
| 普通地块 1 槽，主场 3 槽 | 放什么建筑已有空间成本；主体育场实际占一个主场槽位 |
| 主体育场为主场专有、自动设施，普通地块不能建造 | 商业和文化的外地发展组合不能全部要求再建一座主体育场 |
| 港口只能建在沿海 | 给沿海特色，同时需要内陆可用的商业/远征基础组合 |
| 球探已有付费、计时、地区偏向与三选一 | 可以扩为招募项目，不必重做卡片来源系统 |
| 球探中心已有每玩家最多 5 座限制 | 首版继续纳入容量，不能按无限建球探测算 |
| 训练已有 10 分钟、5 点、上限 99、容量随等级变化 | 可先改变培养选择能力，不先膨胀总属性预算 |
| upgradesEnabled 为 false；升级数组不是已上线效果 | 现在确定专业分支，可与真实升级效果一起实现 |
| 两编队、挂牌/回收/汰换、现有比赛与战术 | 新收益回到现有循环，不新增远征队数量或另一套比赛属性 |
| 体力、伤病长期结算与多数设施效果尚需完善 | 科研康复和远征整备必须等基础状态规则落地 |

“青训”表示俱乐部的人才发掘路线。首版直接使用现有球员库，不附加年龄、潜力、自动评级晋升或新球员模型。

## 三、五条路线的具体内容

### 1. 青训供给：稳定取得阵容需要的人

- 核心：球探中心，专业方向为人才发掘。
- 第一支援：训练中心的新秀培养方向。
- 可选支援：体能恢复中心，支持训练后的常规恢复安排。
- 优先地块：人才资源、需要发掘的国家/俱乐部地区。
- 主项目：联合试训。

联合试训的建议流程：选择位置组及合法地区范围 → 支付费用并等待任务 → 获得位置分布更符合需求的候选 → 仍只选择一名球员。训练设施参与时，可以改善候选的角色覆盖或解锁一次后续培养安排。

这里的主要收益是招募选择能力和球员供给。卡片仍是普通实例，可正常编队、训练或依照既有规则挂牌；一项项目不能在球探端领一张、训练端再多领一张。

长期目标是建立地区招募网络、完成不同位置和地区的发掘项目。基础目标要求真实发掘记录，不通过买入再卖出同一张卡反复增加进度。

投入代价是持续球探费用、候选随机性和建设槽位；青训路线不会同时拥有最强的定向训练效果和最高的金币收入。

### 2. 竞技科研：提高培养的精度

- 核心：训练中心，专业方向为专项研究。
- 第一支援：医疗中心的运动医学方向。
- 可选支援：体能恢复中心。
- 优先地块：训练适配的人才资源、医疗与补给资源。
- 主项目：专项培养课题。

建议把科研成果定义为“训练项目的可选能力”。例如完成某一课题后，能将一次训练限定在已批准的属性组中，或选择其中一部分分配方向。仍遵守现有单次点数与属性上限，先改变精度，再评估是否调整效率。

球员参加训练获得实际成长，俱乐部同时累积该课题的非交易进度。使用不同合格球员或完成不同培养要求推进后续项目；不靠同一张满属性卡重复点按钮刷研究。

医疗/恢复支援在对应系统完成后可提供训练后的整备服务，或解锁伤后复训项目。科研不能凭空增加一个引擎不认识的“战斗力”或士气百分比。

主要收益是更可控的培养、专业训练项目和可用阵容安排。已完成的课题档案可以保留，执行高级服务仍需要合格设施与费用。失去地块后不扣回球员已合法获得的训练属性。

投入代价是占用本可用于供给/商业的训练设施、项目时间和运营费用。科研项目以实作与课题完成解锁，金币不能一次买通全部进度。

### 3. 商业经营：建设稳定的资金来源

- 核心：俱乐部商店，专业方向为商业门店。
- 内陆支援：主场体育场，或训练中心提供足球活动项目。
- 沿海支援：港口的商贸运营方向。
- 优先地块：商圈、良港和周边不同资源。
- 主项目：赞助合同；港口组合可进一步提供跨地区经营合同。

商业门店提供适度、可预测的持续收入。协作项目增加需要实际完成的目标，例如举办一次合格活动、供应规定的自有产出、完成已开放的地区经营任务。首版优先 NPC 合同；不把尚未开放的玩家直接交易作为必要条件。

港口提供跨区域经营选择和运输条件，而不是单纯把所有金币收入乘一次倍数。内陆玩家可通过体育场/活动组合发展商业，港口是另一种组合优势。

主要收益是金币、合同选择和经营规模。金币可用于养成、建设、购买市场球员，使商业与其他路线自然连接。

投入代价是合同成本、资金占用和有限任务容量。经营路线不能单靠持有金币自动获得更多金币，也不能低成本重复开启赞助无限发钱。

### 4. 球迷文化：通过地区活动建立合作网络

- 起步：现有主体育场提供俱乐部活动入口。
- 外地核心：俱乐部商店的球迷分会方向。
- 第一支援：训练中心的社区足球方向。
- 可选支援：球探中心的地区联络方向。
- 优先地块：地区特色、人才资源及后续足球地标。
- 主项目：社区足球活动、地区交流赛、学院合作。

球迷文化把足球认同、地区关系和俱乐部传播转成可操作的经营内容。玩家举办活动或完成 NPC 委托，提升相应地区组织的合作等级，逐步取得当地试训资格、服务预约、地区赛事资格或有限资源合作份额。

合作等级是一份进度/权限记录，不是球员状态，也不增加士气。文化路线的主要收益是接触机会与地区服务，不只发放外观或额外金币。

NPC 资源合作份额建议作为后续项目：玩家用活动与合同换取约定数量或时段的产出，不改变地块归属、不取得驻军权限，也不能直接使用其他玩家的建筑。先在独立 NPC 组织/据点验证，多名玩家可分别合作。

这为少占地玩家提供发展路径。完成社区项目、地区赛事仍可以和足球比赛联动，但基础文化活动不要求连续击败其他玩家。

投入代价是把商店槽位用于球迷分会、投入活动费用和任务时间。因此文化型商店不能同时领取商业门店的全部专业收益。

### 5. 远征开发：扩大可持续探索范围

- 核心：体能恢复中心，专业方向为远征整备。
- 内陆支援：球探中心的前哨勘察方向。
- 可选支援：医疗中心的远征救护方向，或港口的远征基地方向。
- 优先地块：补给、医疗、良港，以及新区域入口。
- 主项目：远征整备、区域勘察、海上出征准备。

恢复/医疗组合支持驻扎在服务范围内的己方远征队，港口组合支持新发起的跨海行动。补给项目消耗费用/资源，为合格队伍提供有上限的体力补给或其他已明确的整备服务。

主要收益是可行动范围、持续出征能力、探索信息和实际挑战获得的资源。它不自动提高比赛胜率，不绕过失败冷却，也不产生第三支编队。

长期目标是完成不同地区的探索和挑战链，建设可用的前进基地。失败、维护和球员轮换形成消耗；重复攻击同一地块不无限增加项目进度或特殊奖励。

## 四、用一套建筑协作规则承载五条路线

建议使用“一个核心设施 + 最多两个支援设施”。这里是服务组合，地图仍使用现有地块，不新增必须手工划定的行政区。

1. 核心与支援必须位于己方同地块，或支援位于与核心直接接壤的己方地块；无需支援彼此接壤。
2. 首版使用土地真实接壤关系，港口航线不自动变成全地图相邻加成。
3. 两种合格设施即可运行基础协作项目；第三种设施改善选择、容量或解锁高阶项目，不作为普通服务的门槛。
4. 每座设施同一时间只绑定一个协作组合，不同时作为多个核心的支援；继续保留未被任务占用的基础服务。
5. 项目涉及的球员、训练席位、医疗床位等按实际占用核算；不得在基础服务和协作项目中双重占用。
6. 重复类型不增加协作层数；加成不向第二、第三层邻地递归传播。
7. 资源按所在地或直接相邻的有效来源提供有限配合；同一收益来源不能被重复计价。
8. 领袖的额外候选/时间/成本优惠计入同一收益预算，不与专业、资源反复叠成无上限乘数。
9. 一个核心只运行一个协作项目；持续经营效果也按确定的组合计算。玩家可在项目结束后重新绑定支援。
10. 失去来源地、拆除或停用时，先结算旧时段的持续收益，再停止下一时段效果；已付费任务按下述规则收尾。

常规球探、训练、基础恢复等继续可以由单座合格设施提供。协作项目是在其上增加新选择，避免新玩家没有三块地就无法正常游戏。

### 开始、结束与失去设施

- 开始项目时锁定费用、参与设施/席位、领袖及资源条件、持续时间与抽取规则。
- 已支付并承诺的经济/招募项目，在服务端托管状态中完成；占地变化不能额外重抽或二次领取。
- 所有权变更时，执行中的球员训练/医疗任务建议采用“安全结束当前任务、停用后续服务”；球员仍属于原玩家，不随建筑转移。此规则需与最终 PvP 结算一并确认。
- 即时驻扎恢复等依赖当前位置的服务，失去控制后停止未来恢复，已恢复部分不倒扣。
- 拆除前必须处理任务与支援绑定；原玩家材料库存及已合法获得卡片不随地块消失。

## 五、建筑升级如何配合路线选择

建议首轮开放 LV1–LV3，功能与等级对应：

| 等级 | 角色 | 玩家看到的变化 |
| --- | --- | --- |
| LV1 | 基础服务 | 球探、训练、经营等原本用途 |
| LV2 | 通用协作 | 可组成基础项目，预览支援来源 |
| LV3 | 选择专业方向 | 获得该分支的项目或服务能力 |
| LV4–LV5 | 后续内容 | 经济和项目验证后再确定，不先开放空效果等级 |

专业互斥针对单座建筑，玩家可在别处建设同类型的另一专业。基础服务仍保留；如以后允许改专业，需要费用、时间和任务结束条件，已获得的俱乐部成果保留。

| 现有建筑 | 专业方向候选 | 具体取舍 |
| --- | --- | --- |
| 球探中心 | 人才发掘 / 地区联络 / 前哨勘察 | 招募选择、文化合作、远征信息 |
| 训练中心 | 新秀培养 / 专项研究 / 社区足球 | 支持人才供给、培养精度、地区活动 |
| 俱乐部商店 | 商业门店 / 球迷分会 | 金币经营、合作与活动资格 |
| 医疗中心 | 运动医学 / 远征救护 | 专项培养支持、出征后的治疗安排 |
| 体能恢复中心 | 训练恢复 / 远征整备 | 训练轮换、驻扎队伍补给 |
| 港口 | 商贸运营 / 远征基地 | 经营合同、跨海行动支持 |
| 主体育场 | 主场统一管理项目，首版不选永久专业 | 组织入口、活动场地；同时运行项目数量受限 |

表格为长期候选，不要求一次开发全部分支。初版只做试验路线用到的分支；没有真实效果的选项不显示。

当前港口沿海限制、球探数量上限和主场专有规则继续有效。不通过开放可随处建造的第二座主体育场补齐组合。

## 六、地块资源与领袖如何参与

资源应改变路线的落地位置：

- 人才地块适合发掘/培养，但同一个槽位需要在球探和训练之间选择。
- 商圈适合商业门店；用于球迷分会会放弃一部分直接经营收入，换取地区活动收益。
- 医疗/补给资源可服务科研培养或远征，两种专业的用途不同。
- 良港提供跨地区选择，内陆组合保持独立可玩。
- 建材是各路线扩建设施的共用支持，建设本身暂不单列为一条终局路线。

首版仍建议金币加统一建材；课题档案、地区合作等级和探索完成记录作为各自进度，不做五种可互换的新货币。

领袖强化一类玩法，但不独占建筑分支。例如商业领袖也可以修建青训组合；玩家后期改变投资方向无需清空账号。领袖冷却和权益继承规则延续前案。

## 七、玩家能如何混合发展

| 玩家选择 | 建设/行动方向 | 获得什么 | 需要补什么 |
| --- | --- | --- | --- |
| 青训 + 商业 | 发掘适合的卡，利用已有挂牌市场出售一部分 | 球员供给与资金 | 自用主力的专项培养 |
| 科研 + 远征 | 专项培养核心阵容，在前进基地轮换恢复 | 培养精度与持续出征 | 新卡供给与建设费用 |
| 文化 + 青训 | 通过地区合作取得试训机会，再发掘和培养 | 地区渠道与阵容选择 | 升级资金 |
| 商业 + 科研 | 用经营收入购买普通/已培养卡，再发展专项课题 | 稳定资金与精细养成 | 地理信息和远征基地 |
| 远征 + 文化 | 发现地区并完成当地活动/挑战 | 探索奖励与 NPC 合作 | 长期维护和球员轮换 |

市场自然产生部分互补关系，但首版不新增玩家之间的资源交易、治疗代办、租借或直接金币转账。商业买入已培养球员是有效路线，同时不能用钱直接购买所有路线进度；需实作的成果仍由对应项目取得。

## 八、真正鼓励多路线的必要条件

### 不同路线必须有自己的目标和成果

| 路线 | 阶段目标示例 | 对应实际成果 |
| --- | --- | --- |
| 青训 | 完成若干不同位置/地区的发掘项目 | 新的合法试训范围或招募项目 |
| 科研 | 完成若干专项培养课题 | 新的有限定向训练能力 |
| 商业 | 完成不同类型的经营合同 | 更丰富的合同、有限经营容量 |
| 文化 | 与多个地区 NPC 建立合作 | 地区赛事、试训与服务资格 |
| 远征 | 完成区域探索链和不同挑战目标 | 新的勘察任务与基地项目 |

进度应从真实项目结算产生，永久卡片权益和阶段奖励只领一次。路线成就不只比较金币总额、土地总数或上线时长；也不要求所有路线最终都必须征服同一数量的玩家地块。

### 优势需要实际成本

- 土地槽位有限，同一建筑高阶专业有取舍。
- 核心和支援绑定有限，不能一座医院支持整个大陆所有科研与远征收益。
- 提高选择精度、减少时间或增加候选都折算进总收益预算。
- 金币是共用资金，各路线都有合理来源；商业擅长规模，其他路线有可持续的基础收支。
- 不强制玩家建设所有设施才能开始正常玩法；共用基础服务保留可用。
- 强化、现有评级和训练上限不因路线凭空突破。

### 后加入者和少占地玩家也能发展

- 基础组合在主场及有限邻地可建立；出生位置分别验证，不要求人人沿海。
- 固定 NPC 委托、项目和补充物资渠道保证不依赖尚未被抢完的中立首占。
- 文化合作份额只能来自明确 NPC 组织，不侵占玩家地块权益。
- 玩家领地争夺仍按未来确定的保护规则处理；不能把玩家不发展 PvP 当作清空其经营成果的理由。
- 精细经营可以逐步推进本路线项目，不用重复等待另一条路线达到相同等级。

## 九、界面怎样呈现

### 地块与建筑

在现有地块面板中显示“当前专业、当前项目、实际收益”三个必要信息。建造/升级前显示能接入哪些邻地设施、项目变化和费用。

选择核心后临时高亮可以配合的地块，并标出图标；默认地图不常驻大量连线或说明。

### 俱乐部发展

从现有玩家信息/主场入口打开一个发展页，集中展示五条路线的当前项目和下一项可获得的能力。布局强调已完成成果与可执行操作，不显示五个没有明确用途的虚构数值条。

### 协作项目

例如：“联合试训｜前场｜候选角色更均衡｜开始”。详细来源点击查看：核心球探、相邻训练、人才资源、领袖。主页面不重复解释何为相邻或何为青训。

训练继续复用选卡界面，招募继续复用球探候选，经营合同复用任务状态，地区活动复用可用的 NPC 比赛流程。必要状态、费用和结果要可见，保持用户要求的简洁风格。

## 十、适合当前项目的最小改造顺序

### 第一批：先证明两条路线有不同收益

1. 整理协作规则、项目的成本/时间/效果表达，以及所有权变更处理。
2. 完成原本计划中的设施基础效果、升级/拆除基础。
3. 只开放“球探 + 训练”的联合试训，以及“商店 + 主体育场”的赞助活动两种基础组合；分别支持两设施起步。
4. 接入人才/商圈两类资源配合；材料按经济基线决定引入时机。
5. 检查同一笔资金和相近可投入时间，玩家是否分别获得可感知的招募优势和经营优势。

这两种组合可先用 LV2 协作验证，不需要一次发布五条路线的完整专业树。随后用 LV3 分支验证同一建筑的选择代价。

### 第二批：做出少占地的文化路线

商店开放球迷分会，训练开放社区足球；增加一个 NPC 地区合作对象、一种活动项目和一项可用服务权益。此时重点验证“同一座商店选商业还是文化”是否值得思考。

文化基础提前放进设施阶段的小范围验证；完整 NPC 网络和地区内容仍放在 M4。

### 第三批：科研与远征联动

服务器时间体力/伤病及医疗/恢复已实现后，增加专项培养课题和远征整备组合。沿海地图再验证商业港口与远征港口的专业取舍。

### 第四批：领袖与更多内容

最后叠加相应领袖，使其加强已验证的路线；扩大项目和资源类型，接入完整地区合作、地标及路线成就。领袖不先于基础路线承担全部差异。

上述排序细化并调整前一提案中笼统的“资源/设施/领袖”批次：先做两个路线样本，再增加文化样本，之后扩科研/远征和领袖，避免只做完若干被动百分比。

## 十一、实施前的验证范围

- 功能：组成/解除组合、专业切换、席位占用、重复开始/领取、失败/取消、断线/重启。
- 状态：施工、升级、拆除、挂牌球员、比赛快照、伤病、领地归属变化。
- 地图：主场同地、多邻地、内陆/沿海、岛屿、无特殊资源、多核心争用同一支援。
- 平衡：相同阶段资金、土地和时间预算下模拟五条路线的 7 天/30 天成果；分别看金币、卡片供给、训练精度、服务资格和探索机会。
- 内容：至少存在两种合理项目选择及一种有效混合路线；如果某路线能低成本买通其余全部优势，需要重新调整成果和成本。
- 数据：项目结算只执行一次；展示历史有界，成果/去重状态与展示日志分离；基于服务器时间和地块变更更新，不逐秒扫描写全世界存档。
- 性能：地图仅按需要显示协作高亮；复用既有缓存/卡片列表优化，避免给每座设施常驻动画。

现有工作树只增加本文和交接引用。没有开启设施升级、改动卡池概率或训练规则，没有迁移真实世界，没有打包。
