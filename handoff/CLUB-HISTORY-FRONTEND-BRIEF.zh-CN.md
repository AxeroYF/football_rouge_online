# YFFM1「俱乐部数据」前端设计交接

## 任务与交付边界

请为足球经理游戏 YFFM1 设计可交互的「俱乐部数据」页面。两版功能合并为一次交付。玩家应能回答三个问题：我的球队历年来踢得怎样？对阵某一支球队谁占优？谁为我的俱乐部贡献最多？

本次交付前端源码、可运行预览和示例数据。用示例数据走通以下交互。真实比赛查询、旧存档回填、永久保存、去重、游戏路由和正式上线由项目侧在收到前端包后接入。

## 入口与视觉

- 左侧导航「球队与经营」中，在「俱乐部」下方增加「俱乐部数据」。主页现有「赛果档案」提供「查看本队完整队史」入口，直达「全部比赛」。侧栏入口默认打开「队史总览」。
- 沿用现有俱乐部主场的深浅主题、球队徽章、分级标识、字号、表格和移动端导航。只设计游戏内容区和必要入口。胜、平、负均有文字或符号，颜色仅作辅助。
- 页头显示球队名称、队徽与统计范围。默认「全部赛季 · 正式比赛」。赛季和赛事筛选作用于总览、比赛、交手与球员榜；荣誉时间线按赛季筛选，明确标出队史纪录的范围。

## 五个页签

| 页签 | 首屏内容 | 交互与明细 |
| --- | --- | --- |
| 队史总览 | 总场次、胜平负、胜率、进失球和净胜球。下方放历季级别与排名、主要荣誉、队史射手前三、交手最多的对手 | 点击赛季看该季比赛；点击射手看本队生涯；点击对手看交锋详情。总场次等于胜、平、负之和 |
| 全部比赛 | 已完赛比赛按时间倒序。每行有赛季、赛事及轮次、主客身份、对手、比分、本队赛果。比分标明主客顺序 | 可按赛季、赛事、主客、对手和赛果筛选，长列表分页或加载更多。有比赛详情或回放时给对应入口。只有比分的老比赛也可查 |
| 交手记录 | 对手列表默认按交锋次数排序，显示队徽、队名、交手次数、胜平负、胜率和最近一次比分 | 搜索并选择对手后，展示总战绩、进失球、主客场拆分、最近五次及所有逐场记录。桌面左右并排，手机点入详情；返回保留筛选与列表位置。胜率与场次同屏 |
| 球员榜单 | 射手、助攻、进球参与、出场、扑救、场均评分六榜，默认射手榜。历史上为本队出过场的离队球员也可上榜 | 点球员展开本队生涯，按赛季展示贡献，标明在队或离队。回归球员合并多次效力记录。主要指标相同显示并列名次 |
| 荣誉与纪录 | 荣誉时间线按赛季显示联赛级别、最终排名、升降级、冠军和杯赛所达阶段。纪录包括最大比分胜利、最大比分失利、最长连胜、最长不败 | 最大胜负按净胜球或净负球评定，可查看并列场次。单场纪录跳比赛，连续纪录展示起止日期、场数和整段赛程。进行中的赛季显示当前排名 |

## 榜单的显示口径

| 榜单 | 主指标 | 同行辅助信息 |
| --- | --- | --- |
| 射手榜 | 进球 | 出场、场均进球 |
| 助攻榜 | 助攻 | 出场、场均助攻 |
| 进球参与榜 | 进球＋助攻 | 进球、助攻分别列出 |
| 出场榜 | 实际出场次数，首发与替补登场各算一场 | 效力赛季、在队状态 |
| 扑救榜 | 门将总扑救 | 出场、场均扑救 |
| 场均评分榜 | 评分总和除以有评分场次 | 有效评分场次；当前筛选范围满 5 场有效评分入榜 |

## 跨页面统一口径

- 胜率为胜场除以已完赛交手场次，平局计入分母。没有比赛时显示「—」。点球大战前的终场比分（含加时）决定本场胜平负，点球比分和晋级结果另列。两回合淘汰赛逐场统计。
- 全部正式比赛涵盖本队参加过的正式赛事。联赛支持筛选 A 级或 B 级，按比赛发生时的级别归类。旧赛制保留历史名称。友谊赛可单独查看，训练赛不进入队史。
- 球队按身份关联，改名后保留交锋历史；球员按身份关联，统计归比赛当时效力的俱乐部。点球大战罚球不计射手榜，乌龙球计入球队比分。
- 显示统计覆盖范围。历史球员资料缺失时，例如显示「42 场正式比赛，39 场有球员明细」。某项指标缺失用「—」，有记录且数值为零才显示 0。缺场导致连续纪录无法确认时标为「可核实记录」。

## 示例数据与验收路径

示例数据单独存放。球队、对手、球员、赛季和比赛之间使用稳定 ID，列表与详情共享同一批数据。按钮和跳转应能传出相应 ID 与筛选条件，便于接入现有比赛详情及回放。用同一套样例演示以下路径：

1. 球队从 B 级升入 A 级。在总览选中 B 级赛季，进入全部比赛后，列表、胜平负和场次相互吻合。
2. 选择交手过多次的对手，查看主客拆分和一次点球晋级的平局。打开该场详情，再返回原对手。
3. 在射手榜打开一名离队后回归的球员，能看到分赛季贡献以及与榜单一致的合计。
4. 从荣誉与纪录打开最长不败的整段赛程，再点其中一场。放入一场只有比分的老比赛，展示详情和回放的可用状态。
5. 展示新俱乐部零场、筛选无结果、旧赛季明细缺失、加载中和读取失败可重试等状态。桌面和手机均能完成搜索、筛选、点入、返回。

## 前端包内容

请交付页面及组件源码、页面样式、示例数据、预览启动方式和简短接线说明。优先采用项目现有原生 JavaScript ES 模块与 CSS，样式限定在本页面范围。若使用独立原型工程，请注明依赖和构建方式。说明中标出五类接入位置：读取队史、筛选及翻页、打开比赛详情、播放已有回放、打开球员效力记录。

项目侧收到包后负责真实数据和存档接入。现有赛季归档列表上限为 12 个条目，长期队史需单独保留逐场摘要与俱乐部球员贡献；从可读取的归档回填，并按比赛身份去重。最终使用隔离存档验证跨季、升降级、改名、转会回归、旧档缺项与重复结算。
