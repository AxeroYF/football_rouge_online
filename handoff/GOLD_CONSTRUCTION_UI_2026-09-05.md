# 金币、建造与施工通知 · 2026-09-05

本轮最终要求：建造按钮只显示图标和费用；金币图标使用普通硬币堆，不使用足球纹样；移除地图常驻的可见/探索/相遇计数；施工中的设施在右上角显示进度。用户同时明确后续不必每轮备份，当前工作树即主线。

## 实现

- assets/ui/gold-coin.svg：两叠普通金色硬币，24×24 SVG，16/20/24px 场景可用，没有足球或文字图案。
- client/ui/currency.js 与 styles/currency.css：统一 goldAmountMarkup(value, { signed }) 和 goldIconMarkup()；金额使用千位分隔，图标和数字保持一行。金额有完整金币屏幕阅读器标签，错误说明和普通文案保留文字。
- 所有现有玩家界面的金额单位已接入：顶栏余额、六种设施建造费用、球探发掘费、强化页余额及保卡、保卡历史详情、比赛奖励。原图片资源不变，只有新增 SVG。
- 建造按钮删除可视“建造”副行，图标与费用居中；不足和提交状态仍禁用，并用 aria-label/aria-busy 表达操作状态。缩小旧的 span 样式作用范围，避免灰字覆盖金额以及球探金额嵌套成面板。
- createCampaignFogController 的 showStatus 默认 false，默认不创建或挂载统计 HUD。仍保留诊断时显式开启的能力；未修改迷雾范围、相遇、预览或镜头逻辑。
- client/buildings/construction-notifications.js 与 styles/construction.css：订阅现有 campaignStore 的 buildings.territories，只显示可管理且归属当前玩家的施工设施，无新增服务端请求或接口。
- 每秒就地更新进度、百分比和倒计时，避免重建任务卡导致定位按钮失焦；沿用服务端时间校准，重复旧时钟样本不重置计时。倒计时归零时显示“等待完工确认”，服务端状态转为 active 后显示“设施建成”，8 秒后自动收起；仅提示本会话观察到的完成，不刷出历史建筑。
- 任务显示名称、LV、所在地和旧设施图，点击箭头定位并打开地块详情；切换账号、失去归属、建筑移除时清理任务。没有任务时停止秒级定时器。
- index.html 与 app.js 接入新资源、任务容器与缓存版本 gold-ui-v1。强化圆形按钮和最近 50 条滚动修复继续保留。
