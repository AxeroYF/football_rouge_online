# 前端优化包游戏内验收

2026-11-19，对照 `yffm1_ui_redesign_bundle.zip` 的部署说明和五个源文件，在本机 Chrome 打开游戏，使用隔离存档注册经理、选队、挂牌、交易、合卡并观看正式 V4 联赛。包中旧版页面结构按当前赛制和交互接入。构建命令为 `npm run build`。

## 逐项对照

| 包内项目 | 游戏内检查与结果 |
| --- | --- |
| 全局字体、深浅主题 | 在 2560×1440 逐一打开 14 个主页面并切换主题，核对实际文字、面板颜色及布局。主题选择会保存，设置说明已同步手机端表现。 |
| 俱乐部主场 B 版 | 比赛主卡下方两行各有两块内容。积分榜可进对手档案，近期比赛可折叠和展开。 |
| 对手球探档案 | 从积分榜进入 AI 球队档案，切换完整名单、AI 战术与历史页，名单显示 23 人，可预览领先站位。 |
| 商店、背包展柜 | 商品网格随可用宽度增加列数。切到背包的球员卡管理，可看到当前经理的真实库存。 |
| 经典合卡 | 在游戏设置切换经典版，核对两种主题下的卡槽和仓库。1280 像素窗口保留双栏；用有重复卡的库存实际打开批量合卡，确认可合成数量及提交按钮。 |
| 新版合卡 | 清除闲置粒子节点及旧样式对抽屉底色的覆盖。修正鼠标移入打开抽屉后，紧接着的第一次点击会把它收回的问题。用六笔真实合卡覆盖蓄力、碰撞、冲击波、结果揭示，以及普通成功、+4 金色成功、失败降级、关闭动画、跟随系统减弱及手动开启动画。结果用隔离卡片和固定随机源复现。 |
| 交易市场三标签与交易表 | 检查单卡、所有权和玩家交易入口。在真实挂牌行核对球员卡、姓名、位置、总评、卖家、价格和操作。修掉旧样式把位置标签拉满及金币单位换行的问题。布局按交易区可用宽度切换。在 2560、1130、390 像素窗口分别为六列、两列、两列，操作按钮均可点到。 |
| 双边交易单 | 两位测试经理各提供一张强化卡；顶部交易单同步显示两张卡。我方附带 200 金币，提交后显示等待接受，对方接受后刷新显示交易成功。 |
| 比赛电视台 | 修复 V4 正式轮次只补入本队比赛的问题。真实联赛同轮 8 场全部显示，本队置顶，卡片显示对应的 A/B 级别、天气、已播比分和分钟。点击其他球队可直接进入直播。服务端另验证杯赛同轮 8 场与结算后退场。直播、预告并存及手机预告布局采用可复现的赛事样例。 |
| 战术板 | 2K 保留纵向球场和三栏。实测拖动站位、自动保存后刷新、赛事方案下拉绑定和球员状态预览，覆盖桌面和手机。 |
| 收件箱 | 实测分类、分页、按需读取、跨页已读和邀请到期后的状态。覆盖手机详情及 2K 列表与阅读区。 |
| 预测、日程、榜单、球员信息 | 两种主题逐页核对。球员信息额外检查搜索与强化榜单两条入口。 |
| 俱乐部经营 | 将报价及合同样式接到实际组件。用新经理接受初始赞助，核对报价转为生效合同后的底色和可读性，并打开荣誉室。 |
| 冠军杯 | 将优化包的奖杯金色、比分和对阵卡片应用到当前十六强淘汰树。桌面双主题、手机局部滚动、两回合总比分、单场决赛与战报入口分别检查。 |

页面宽度巡检覆盖 360、390、768、1024、1366、1920、2327 和 2560 像素，共 112 个页面与宽度组合。另测 63 个子页、窗口和侧栏组合，整页横向溢出为零。2327 像素近似 2560 宽屏在浏览器 110% 缩放时的可用宽度。

## 原先失败的九项

| 用例 | 处理和验证 |
| --- | --- |
| AI 队徽 | 改验 16 支球队各自的真实俱乐部徽章，核对积分榜与档案。 |
| 商店四列及徽章包 | 更新为自适应网格与实际导航，同时保留两类徽章包的视觉区分断言。 |
| 友谊赛邀请 | 从两位经理实际创建的轻量邀请验证两小时边界及已接受状态，保留轻量请求的接线检查。 |
| 新赛季重置 | 检查玩家卡片、所有权、交易记录均清空，16 支 AI 队各自重新拥有 23 人名单。 |
| 主题默认值和保存 | 验证默认深色、旧偏好读取、深浅切换与重新加载。修正设置说明。 |
| 战术板拖动 | 验证球员和阵线两条拖动路径均局部更新并保存，另在浏览器实际拖动与刷新。 |
| 手机收件箱、卡片及杯赛 | 保留卡片特性与邮件操作检查；杯赛改验淘汰树、两回合战报入口、总比分及晋级结果。 |
| 996 固定体能 | 将前端检查接到战术板实际调用的赛事可用性计算，用同一球员验证固定体能 94 与赛前轮换。 |
| 冠军杯阶段数 | 按现行赛制验证十六强、八强、半决赛、决赛分别有 8、4、2、1 组对阵，并区分两回合与单场。 |

原六个测试文件共 147 项，修复后 135 项通过、0 失败；12 项为项目原已跳过的暂停版 X 球员用例。V4 正式调度、主题设置和 AI 身份测试另有 17 项通过，直播 HTTP 权限测试通过。

扩展运行旧的完整联赛测试文件时，球员池数量、体能轮换和领先落后战术仍有历史失败。该次长跑超过项目的单文件 180 秒测试时限后停止。此前对照改动前提交已有 28 项基线失败，不能据本次结果认定全仓通过。[联赛历史逐项对照](../outputs/league-regression-20261119/联赛测试对照.md)
