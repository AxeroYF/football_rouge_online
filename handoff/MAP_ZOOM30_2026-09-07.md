# 大地图 30× 缩放 · 2026-09-07

按用户要求，正式大地图和独立三维地图预览的最大放大倍率从 25× 提升至 30×。

## 实际修改

- app.js：以 Leaflet z3 为 1×，最大 z = 3 + log2(30)，约 7.906891。
- shared/config/fog.mjs：迷雾视口缩放约束同步到 30×，不会被旧上限卡住。
- client/map-three/preview.js：地图预览惯性滚轮上限改为 log2(30)，界面显示 ×30.0。
- 兼容 Leaflet 地形瓦片显示上限仍为 ceil(7.906891)=8，原生资源仍钳制到 z7，不请求不存在的 z8。
- index.html 和 three-preview.html 更新脚本缓存标识为 20260907-map-zoom30-v1。
- 建筑图标继续使用原尺寸上限；相关检查增加 30× 边界。奇观单体模型图鉴的独立相机缩放不在本次大地图修改范围内。

## 验证与使用

- 55 项地图、迷雾、惯性滚轮、建筑图标及三维预览相关检查通过。
- 既有 Leaflet GridLayer 测试覆盖 20×、22.7×、25×、29.9×、30×，均继续使用原生 z7。
- 完整 npm run check 通过：70 + 482 + 97 = 649 次测试执行，0 失败。
- 独立临时静态服务和无头 Chrome 加载实际 atlas 预览，以滚轮达到 ×30.0；继续放大仍是 ×30.0，反向缩小到 ×21.2；无页面异常或相关资源加载失败。
