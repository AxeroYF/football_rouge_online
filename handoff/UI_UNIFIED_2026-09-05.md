# UI 统一外观 · club-ui v1

用户要求统一现有 UI，并保留可回退版本。此版本落实此前 `UI_STYLE_AUDIT_2026-09-05.md` 的深绿灰＋暖金方向，范围为外观，不改业务流程。

## 当前生效范围

- 登录、注册、建队、初始选卡外壳；地图顶栏、账户菜单、地块详情、建造操作、悬浮提示和任务通知。
- 球队管理、YOOGLE 搜索、球员档案、背包；训练、球探、强化主界面及结果/批量操作弹窗。
- 战术外围控件、比赛直播外围面板与赛果；现用后台与旧后台入口。
- 普通面板为 `#1A241F`，抬高控件 `#24312A`，凹入区域 `#141E18`，主操作 `#D4B365` 配深色文字；状态和模块色保留小面积用途。
- 页面标题通常 22px、上下文侧栏 18px；普通操作 40px、紧凑操作 32px、关闭按钮 36px；8/12/16px 圆角。数据使用等宽数字。信息密集的球场及卡牌继续由原组件控制尺寸。
- 保留己方地块面板暖棕区分、地图所有权颜色、海洋/迷雾、球员卡评级、比赛主客队/状态图例、开包和强化演出。没有替换任何图片。

## 代码与回退

- 新增 `styles/ui-theme.css`，在原模块 CSS 之后加载。所有规则限定于 `html[data-ui-theme="club"]`，原样式文件未修改。
- `client/ui/ui-theme.js` 在 head 同步读取 `ui` 参数，默认 club；`?ui=legacy` 使用旧外观。已有查询参数时加 `&ui=legacy`。不写 localStorage、账号或后端状态。
- `index.html`、`admin-v2.html`、`admin.html` 接入主题；后台另加 `admin-ui` 类限定后台样式。主题不提供新的游戏内设置或业务入口。
- 修改前完整前端快照：`YDL_backup/ui-before-unified-20260905/manifest.json`，91 文件、1,012,743 字节，SHA-256 已核对。包含当时的 HTML、JS、client、styles 和交接入口；资源与存档未改。
- 快速回退优先使用 URL 参数；完整文件快照供需要恢复文件时使用，不应覆盖此后无关业务修复。
- 这是纯前端变更，刷新页面即可；无需重启服务。原窗口尺寸、独立滚动、Esc/焦点恢复和业务逻辑沿用现有实现；本次没有声称补齐所有嵌套弹层行为。
