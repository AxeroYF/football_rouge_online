# 黄狗风云 UI 与颜色风格审计 · 2026-09-05

## 结论与范围

建议统一为「低饱和深绿灰＋暖金」：共享窗口底色、文字层级、按钮和边框；模块身份主要通过图标、短色条和状态色表达。地图领地色、卡牌稀有度、球场与奖励演出继续承担各自的内容表达。

本轮是代码与已提供截图的静态评估，不是浏览器逐页实机验收。检查 /game 的入口、主功能与多级弹窗，以及 /admin 当前入口；核对 CSS 加载顺序、末尾覆盖、现用生成模板和窗口管理器。没有更改游戏代码、启动服务、操作浏览器或替换图片。配色稿是提案示意，尚未应用到游戏。

## 最值得先解决的五件事

1. **主操作缺少稳定识别。** 登录橙色、背包绿色、训练棕金、球探紫色、战术黄绿色。统一主操作为暖金底＋深色字；次操作使用低饱和底色和细边框；危险操作只在确实涉及删除、消耗或不可逆动作时使用危险语义，不把所有取消按钮都标红。
2. **面板和通知底色随模块改变太多。** 全站使用同一组深浅层级；训练、球探、比赛和移动通知采用同一种结构与间距，仅图标、短色条和状态标记不同。
3. **同级控件的大小不一致。** 关闭按钮可见尺寸包括训练／球探 30px、强化 32px、背包 34px、球队／球员详情 38px；标题为设施 19px、强化 20px、背包 24px、球队／球员详情 26px。尺寸应随窗口等级规范化。
4. **字号与字体规则分散。** 标题混合 Georgia／微软雅黑、Arial 和通用无衬线；中文可能回落到同一字体，拉丁字符与数字仍有差异。数据面板存在 8–11px 小字。统一中文无衬线正文，数字使用等宽数字；品牌字体可作为有意识的例外。
5. **已有窗口规范尚未覆盖所有弹层。** 标准／加宽窗口具有互斥、Esc 和焦点恢复，小型窗口具有模态标记和关闭行为；训练选人、强化子对话框等仍有各自逻辑。后续统一时补齐最上层 Esc、焦点约束／返回、点击遮罩、未保存修改与忙碌状态规则，不直接假设已全部一致。

建议色板的纯色文字／背景对比度计算：主文字对面板 13.15，次文字 8.34，辅助文字 4.84；深色按钮字对金底 8.71。仅是静态颜色计算，不能替代半透明叠图、状态切换及实际字号的页面验收。

窗口尺寸沿用已有认可：标准 1600px、加宽 2180px、球员档案 1180×820。补充共享的上下文侧栏（约 350–360px），简单确认建议 480–560px 内容宽度。训练选人等已按内容优化的尺寸继续保留，统一外观与交互规则即可。

## 实施顺序

1. **基础层与样板。** 建立命名清楚的 ui 颜色、文字、间距、阴影变量；定义主／次／危险按钮、输入框、标题栏、标签、通知卡和进度条。以地图顶栏、球队页和地块侧栏先验证整体方向。
2. **高频工作区。** 应用到球队、YOOGLE、背包、战术外围及强化，统一筛选和操作区。保留卡牌、地图、球场内容色；先确定已用组件，再移除不再使用的旧覆盖。
3. **设施与二级弹层。** 训练／球探使用同套侧栏，选人／结果／确认层统一关闭和键盘行为，右上角任务卡统一尺寸与结构。
4. **完整流程。** 补登录建队、比赛直播／赛果、开包外壳及后台，逐条验收切页、嵌套窗口、未保存提示、任务完成、不同屏宽和多语言球员姓名。

## 实施时的代码重点

- index.html 加载 16 份 CSS（含 Leaflet）；其余 15 份自有样式存在共用与模块规则混合，修改时须按加载顺序核对最终覆盖。
- styles.css 开头已有 --shell／--surface／--gold 等变量，但模块又定义 --bg／--panel／--league-yellow 等独立体系。
- s4-tactics-original.css 与 styles/enhancement.css 保留移植规则及 light-theme 分支；当前强化由文件末尾的 .enhancement-window 紫色规则覆盖。不能把文件里所有颜色都当作当前可见配色，也不宜一键全局替换十六进制色值。
- 通用 .button、.field 等选择器应逐步限定到组件或模块，减少移植 CSS 影响其他页面的机会；先迁移再移除旧样式。
- client/ui/WINDOW_STANDARDS.md 的规范可继续扩充。实际接入的强化也是加宽窗口，背包亦采用 small-window，文档应同步这些实际用途。

## 后续验收重点

在 2560×1440、1920×1080、1366×768，以及实际支持的小屏尺寸检查布局；高分屏按 CSS 像素和系统缩放分别确认。通过同一个球员、同一任务在多个页面中的卡片、状态和操作进行对照。验证地图高低缩放下的浮层辨识、长文本截断、表格滚动、键盘焦点和嵌套窗口。以上是后续改造验收建议，本轮没有执行浏览器验收，也没有启动 UI 改造。
