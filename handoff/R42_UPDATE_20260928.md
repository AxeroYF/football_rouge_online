## 安装

将 yellowdogs-hot-update-20260928-r42.tar.gz 及对应 .tar.gz.sha256 上传到 /home/admin 后执行：

```bash
cd /home/admin && sha256sum -c yellowdogs-hot-update-20260928-r42.tar.gz.sha256 && tar -xzf yellowdogs-hot-update-20260928-r42.tar.gz && cd yellowdogs-hot-update-20260928-r42 && sudo bash update.sh --check && sudo bash update.sh apply
```

看到 Installed: 20260928-r42 后刷新游戏页面。安装器先校验 R41 代码基线，停止服务、备份代码与存档、安装并重启；健康检查失败会自动尝试回滚。更新期间短暂中断服务。
