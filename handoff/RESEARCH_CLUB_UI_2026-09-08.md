# 科研 UI 风格、居中与可读性 · 2026-09-08

用户反馈浅色科技 UI 与游戏不符、描述过多、内容未垂直居中、字体过小。本轮仅修正展示，保持四方向和独立对象的等级规则。

## 已完成

- 使用游戏共享 --ui-* 配色：深绿底色、抬高面板、米白文字、金色强调，统一窗口圆角与选择器。移除蓝色顶栏、浅色底图、纹理。
- 入口只保留四张图标／名称／关键数值卡片；删除俱乐部发展、二次标题、引导段落、编号、卡片底部重复操作文字、整个底部说明栏。
- 等级详情移除重复作用描述、累计说明和重复统计，保留本级增益、必要前置／需求；强化仍显示基础与研究后概率。研究未启用仍由禁用按钮明确呈现。
- research-content 使用可滚动纵向 flex，内容 section 上下 auto margin，空间够时居中、内容超过可用高度时正常从顶部滚动。入口、选中对象工作区、生物占位均一致。
- 桌面标题 26px、方向名 26px、关键说明 18px；控件和详情为 16–18px；等级增益 36px。手机标题 21px，正文最小 15px，关键数值保持醒目。

## 验证

11 项研究规则／标准窗口测试通过；44 项隔离浏览器检查通过。明确检查共享深绿底色、减少文案、字体下限、方向卡片垂直居中、1600×1230 长屏居中、研究工作区居中，另回归独立对象等级、概率、自动同步、刷新保存、账号隔离与 320／390／768／1280px。
