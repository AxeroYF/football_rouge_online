## 风格和参考

延续奇观的低多边形轮廓、暖石材、分色屋顶、蓝绿玻璃、植被、金属细节与微缩基座。现有 ModelKit 几何工具继续复用，设施使用独立材质表，不修改奇观网格、颜色或效果。

参考文明 VI 的城市在地图上实体扩张、区域有可辨认建筑集合的表达方式，转换为本项目五级扩建方案；[Firaxis／2K 官方 Steam 介绍](https://store.steampowered.com/app/289070/Sid_Meiers_Civilization_VI/)及其官方手册入口是参考来源。五级结构、具体造型和颜色是本项目设计，并非文明 VI 原有五级规则或原版模型。参考素材为公开介绍与图像，全部几何在本项目重新制作。

设施统一 +Y 向上、+Z 为前方、底面归零，横向最大占地归一化为 1；七类设施的固定基座利于五级比较。单位使用圆形石质棋座。材质颜色、粗糙度、金属度写入 GLB，全部无需外部贴图／运行时 CDN。望远镜、球衣、队旗等均为实际网格；玻璃和水采用适合地图的有色不透明近似。

这是静态资产；人物没有骨骼、行走动画或自动阵营换色。GLB 分组保留了主体、屋顶、标志、设备、人物和道具，方便后续继续迭代。

## 游戏接入方式

现有地图仍使用 Leaflet 图像标记，本轮把标记图片替换为新 GLB 的透明渲染图；不是把 111 个 GLB 同时放进三维地形场景。图鉴中可以自由旋转真实 GLB。

- 设施地图标记与点击详情按 building.type＋当前 level 选择对应模型图像。
- 建造列表展示 LV1；球探／训练中心窗口、施工通知、拆除确认与服务端设施展示返回使用相应等级图像。
- 远征战棋、地图球探、球探列表和详情同步新图像。默认 tokenId、移动逻辑、点击入口与进度提示保留。
- shared/config/facility-art.mjs 是统一路径与美术等级源，含缓存版本；未知自定义设施仍保留原图像回退。
- 已有旧图标素材保留。没有改变设施价格、能力、工期、数量、资源产出或球探任务。
- **BUILDING_RULES.upgradesEnabled 仍为 false。** LV2～LV5 是已备好的美术资产，不代表升级功能已开放。隔离浏览器里的 LV3／LV4／LV5 来自专用展示夹具，不是通过新升级玩法取得。

包含服务端图像路径调整，旧游戏服务需要用户自行重启后 Ctrl+F5；独立模型图鉴无需游戏服务即可看。没有启停用户原有游戏服务、读写真实存档、提交／推送、打包或部署。奇观效果仍等用户明确通知后接入，本轮没有读取后台奇观草稿。

## 代码与复现

- shared/config/facility-art.mjs：七类五级描述、单位定义、版本和图像选择。
- client/facility-models/facility-kit.js：材质与公共几何；facility-models.js：35 个设施；unit-models.js：两个单位。
- scripts/build-facility-models.mjs：GLB／catalog／构建统计；scripts/review-facility-models.mjs：图鉴渲染、游戏图标与总览。
- scripts/review-facility-game.mjs：独立游戏服务与临时账户验收。
- assets/facilities/catalog.json：每个模型三档路径、哈希、大小、几何统计、等级变化；models/、thumbnails/、icons/ 为实际资产。

命令：

    npm run build:facilities
    npm run review:facilities
    npm run test:facilities
    npm run preview:facilities
    node scripts/review-facility-game.mjs

几何调整后依次构建和渲染；渲染脚本需要本机 Chrome 及 Playwright／Sharp，可使用项目依赖或当前 Codex 已配置运行依赖。纯 GLB 构建仅使用项目现有 Three.js，未增加 npm 依赖。
