# 598 块正式地图、中立奖励与开发迷雾 · 2026-09-08

状态：已实现，已完成隔离测试。正式入口仍为 /game；旧服务进程需要由用户重启后加载新的地块数据与接口。

## 本轮范围

1. 正式地图从 1,470 块压缩到 598 块，欧洲 433／南美 165。
2. 接入六类中立地块征服奖励，攻击前点击／悬浮可看预期奖励。
3. 将已认可 Demo 的建筑、山脉、视角和领土外缘表达接入正式 Three 地图。
4. 地图左下角、小地图上方增加开发迷雾开关，支持关闭全图迷雾和恢复正常视野。

## 地块和产出

固定合并清单：assets/data/territory-merge-plan.json；地图版本：20260908-world598-v1。
清单完整覆盖旧 1,470 块，每个旧 ID 只出现一次；单独保留的地块沿用 ID，合并区域使用稳定 ID，旧别名递归映射到最终 ID。
保留国家代码、核心／非核心规则、84 个城市和 51 家俱乐部。伦敦的 33 个小区归并为一块，仍属于五家豪门的联合驻地。
最终 38 块豪门领地、327 块有真实海岸的领地；奥地利和瑞士没有虚假海岸。
新建索引包含 buildAnchor 与 buildRadiusKm，锚点严格位于真实多边形内部。24 块小国／岛屿例外继续保留。

资源版本：20260908-world598-resources-v1。以新多边形重新采样地形，不把旧地块收益相加。
257 块单产、293 块双产、48 块三产，单块设计预算 8–12，两个大洲平均预算约 10。
金币是余额；生产力、科技值是当前能力，不积累。金币结算、建设平均分配和原有槽位规则保持有效。
地块面板与悬浮提示共享资源和奖励数据；地块产出不显示“/小时”。

重建正式数据：
`npm run build:territories`
该命令依次执行地块、海岸、政治边界、资源配置、内容缓存与资源图鉴生成。日后调整合并区域应改固定清单，而不是再次运行旧的自动候选评估覆盖正式地图。

## 中立奖励

按世界／赛季种子与地块 ID 固定抽取一次，并将整份奖励持久化到 world.neutralRewards。
失败重试、刷新和换一个进攻者不会重抽；同一中立奖励只能被领取一次。俱乐部和玩家领地的征服不会发这类奖励。
战斗结算保存失败时，领土、账号、赞助合同和奖励领取记录一起回滚。

| 类型 | 初始权重 | 首批数量 |
| --- | ---: | --- |
| 金币 | 15% | 1,500–3,500 |
| 珍奇球员卡包 | 15% | 1–2 包 |
| 赞助合同 | 35% | 1 份待签约合同 |
| 球迷 | 15% | 100–500 |
| 一次性生产力 | 10% | 100–300 |
| 研究进度 | 10% | 80–200 |

每块只给抽中的这一类奖励，已替换原来“固定金币＋卡包，再抽赞助”的正式结算逻辑。
赞助品牌来自现有 18 品牌；普通／球场冠名／球队冠名按 70／20／10 分配。
合同维持 1／2／2 天、每小时 200／300／600 金币，获得后待签约，签约后开始计时，仍受 3／1／1 名额约束。
球迷增加到 account.resources.fans。
生产力和研究奖励分别保存到 account.pendingNeutralRewards，不增加日常资源余额或产能。

一次性生产力：
- 获得后自动打开待处理窗口，可投入自己的在建项目，或选择拥有合法槽位的领地新建。
- 新建使用生产力方式，项目创建和奖励投入在同一保存事务完成，不扣金币。
- 未选择、无可用项目或请求失败时保留为待处理奖励，地图左下角持续提供入口。
- 请求幂等；不能投入他人领地、已经完成的项目或重复消耗。
- 投入上限为项目剩余需求。选择时明确显示超过需求的部分不保留，结算记录 appliedProduction 与 overflowProduction。
- 生产力仍按全部在建项目平均分配，奖励导致完工后会重新分配。

研究奖励：保留为下一项研究的一次性进度，待研究系统开放后接入消耗；本轮没有开放研究系统或应用奇观效果。

## 地图视觉

正式图层加载实际设施 GLB，使用现有 LV1–LV5 对应资源。按材质颜色合并几何，减少每座设施的绘制调用。
设施按多边形内部空间安排；普通园区最多遵循当前合法建筑数，历史建筑全部保留。已有建筑槽位限制没有扩张。
港口依据海岸线定向，其他设施适当整平场地、清除重叠树林，多设施园区增加连接小径。
同一地块模型可用后隐藏原 PNG 组；模型加载失败时保留原有入口。悬浮／键盘焦点以模型轮廓高亮，没有矩形底框。
低倍缩放时合并数量标签，近景显示设施等级与详情；点击实体建筑可以打开球探、训练或地块设施面板。
固定相机改为俯仰 40°（相对地面约 50°），保留原 30× 放大上限；地形与业务覆盖层使用同一投影。
连续山脊提高起伏，增加岩面明暗与山顶积雪，保留原地理高程；采用较柔和的暖光。
政治边界按归属合并，只加强势力外缘；同势力相邻地块不重复绘制外边界，内部线和领土底色降低强度。
原独立 Demo 仍保留用于对照；旧照片式地形与 Leaflet 兼容入口仍可访问。

## 开发迷雾

位置：左下角小地图上方，“迷雾：开／关”。
切换后同步服务器的可见地块、建筑、奖励和客户端地形加载。关闭时可查看全部 598 块。
关闭迷雾不会把全图写成永久探索记录；重新开启恢复正常探索与当前视野。偏好按开发账号保存，刷新有效。
NODE_ENV 不为 production 且 HOST 是本机环回地址时启用；其他开发主机可显式设置 CAMPAIGN_DEV_TOOLS=1。
生产环境拒绝开发接口。入口 POST /api/campaign/development/fog，要求现有账号认证。
生产力指派入口 POST /api/campaign/rewards/production，服务端验证奖励和建设条件。
