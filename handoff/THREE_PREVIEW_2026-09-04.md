## 首版能力

- 固定 Three.js 0.185.1；本地打包模块，无运行时 CDN。npm run build:three-vendor 复制官方模块和许可证；npm run dev 前会自动执行。
- 正交相机、0–60° 倾角、右键旋转、左键平移、鼠标锚点惯性缩放 ×1–×16。
- 欧洲、英伦、南美洲、斯瓦尔巴四个定位预设；省界开关、地形开关、阴影开关，厚度和曝光调节。
- 共 1470 个地块，187533 个顶面三角形，基础地理对象合并为 6 个；小地块简化退化时保留原轮廓，确保梵蒂冈不丢失。
- 海岸侧壁是真实三维几何，可投影到海面；顶部山脉仍是已有 DEM 烘焙纹理，不是可改变光向的真实高程网格。
- 共用现有南美洲轴交换，再投影到 Web Mercator XZ 平面；不会把展示坐标当作真实经纬度再次变换。
- 省份拾取使用地面射线和空间索引，保留多边形孔洞；只显示静态元数据，不读取登录状态，不执行游戏 API，不写入任何玩家存档。俱乐部初始分类不是实时玩家领土状态。

## 加载与资源管理

- 每个区域永久保留 z3 粗纹理做回退；按视野选择 z3–z7，细节最多规划 100 张。
- 并发最多 6 个请求，纹理缓存上限 160 张（含粗纹理），淘汰时 dispose 纹理、材质和几何。未加载完成的陈旧回调不会重新创建已销毁场景。
- 高 DPR 上限 1.5；相机变化后约 100ms 更新可见瓦片；静止时不重复绘制场景，页面隐藏暂停更新。
- 缺失瓦片会提示并允许重试，保留粗图/矢量底图；缓存预热不代表所有电脑上都能无等待进入未访问区域。
- 用户已有 4370 服务仅用于只读资源检查；本轮未启动、停止或重启服务。浏览器视觉验收由用户执行。

## 验收

1. 打开 /three-preview.html，对比 /game；先查看英伦海岸的侧壁、影子和山地纹理。
2. 拖动、滚轮缩放至 ×16，再切换南美洲和斯瓦尔巴；确认纹理与轮廓无偏移。
3. 点击省份检查拾取，Esc 取消；尝试关闭纹理和调节大陆厚度以确认真实几何。
4. 修改倾角和光照，记录希望保留的参数。右上性能数据是实时渲染统计，不是性能承诺。
5. 首版只做地图视觉和基础交互，不包含建筑、战棋、海路、天气、账号与比赛流程接入。

## 验证命令

- npm run test:three：投影、UV/裁切、预算、孔洞、全部地块构建、加载失败回退、缓存释放与只读隔离。
- npm run check：原有检查和测试；posttest 自动执行 Three.js 专项。
- 预览 HTML、样式、四个模块与四份 Three.js 依赖的本地 HTTP 检查均返回 200 和正确 MIME。
- 不以静态检查或 Node 几何测试代替浏览器 WebGL 渲染验收。
