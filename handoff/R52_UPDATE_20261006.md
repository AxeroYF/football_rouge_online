## 服务器热更新

将压缩包与同名 `.sha256` 文件上传到服务器 `/home/admin`，然后运行：

```bash
cd /home/admin && sha256sum -c yellowdogs-hot-update-20261006-r52.tar.gz.sha256 && tar -xzf yellowdogs-hot-update-20261006-r52.tar.gz && cd yellowdogs-hot-update-20261006-r52 && sudo bash update.sh --check && sudo bash update.sh apply
```
