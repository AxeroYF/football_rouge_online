# 阵型研究正式接入 · 2026-09-08

## 本轮覆盖前序预览规则

用户已确认每方向 Lv.1–5 工作量为 100、200、400、800、1600，按俱乐部科技值每小时推进，全俱乐部同时一项。科技是即时产能，空闲期间不囤积。

- 三个自定义槽位保留。未确定阵型时可编辑十个外场圆点、名称和位置线；研究方向禁用。点击“确定阵型”写入服务器并锁定几何，才可选择方向并开始研究。确定后不提供改型／重置，避免成果迁移到不同阵型。
- 门将以固定 1 号圆点显示；外场编号 2–11。门将固定 x=50、y=94。
- 研究战术板改用一层 SVG 足球场线，去掉旧 CSS 伪元素／圆弧叠加，只有一个中圈、中线和两个正确截取的禁区弧。
- 研究方向按钮仅在完成后显示对应 +x%；移除五级预览选择器，只展示当前等级／增益、下一等级／增益、科技需求、研究按钮及当前项目进度。
- 右上角信息栏显示阵型、方向、目标级、进度、估计剩余时间，并提供“中止”。中止前结算到实际时间；清空当前未完成级的工作量，保留所有已完成等级。没有科技库存返还。中止／完成后项目通知消失。
- 研究页面和地图通知都可中止，均明确提示本级进度清零。旧浏览器草稿可以继续编辑并提交确定；已确定阵型、实际等级和项目以服务器为准，不把旧预览等级转成成果。

## 后端与结算

`server/application/formation-research-service.mjs` 接入 CampaignService。

存储：`account.formationResearch`，含 schemaVersion、revision、三个 slots 和一个 active。确认形状、已完成等级、开工时间、累计工作、需求和当前项目均持久化。

接口（现有 Bearer 鉴权）：

- POST `/api/campaign/research/confirm`：revision、slotId、formation。
- POST `/api/campaign/research/start`：revision、slotId、direction。
- POST `/api/campaign/research/cancel`：revision、jobId。
- GET 原 campaign state 中增加 `formationResearch` 公共视图，包含 serverNow、当前科技速率与实际研究需求。

服务端校验十点、位置和参考线边界、至少一名前／中／后场，忽略客户端成果级别；确认后不可再次编辑。revision 防过期操作，jobId 防旧中止请求取消新项目。

研究结算放入原 CampaignService.save 的经济分段事务：使用 TerritoryProductionService 提供的 fanIncomeIntervals 每段 `units.science / 1000`，准确跨球迷增长、领地和奇观完工产速变化，不使用当前速率回算离线历史。完成时间落在对应段内，超额工作不进入新项目。磁盘保存失败回滚研究状态与资源分段。

雅典卫城通过现有 `wonders.researchRequirement(account,'formation',work)` 在开工时计算 20% 减免，并锁定该项目需求；后续奇观变化不改已开项目需求。发起正式挑战前结算正在研究的项目，确保最新已完成成果进入比赛快照。

## 战术板导入与锁定

默认／领先／落后站位按钮旁新增“导入阵容研究”。弹层仅列自己已确定的三个槽位，导入当前编队的当前站位；外场按主副位置适配分配，门将固定。

绑定保存于 `planSnapshots.__s4V2.researchFormationIds.position1/2/3`。导入后不能拖动球员坐标或位置线，职责可改。替补替换继续复用原槽位坐标，不改阵型几何。可“解除使用”，恢复自由站位且不再使用该阵型加成，研究成果保留。

服务端 saveTactics 校验绑定必须来自该账号已确定槽位，十一位置的几何集合和四条参考线必须完全相同；伪造坐标不能绕过。新增战术保存失败时的账号战术／编队回滚。

`buildAccountMatchSeat` 再次校验几何和绑定，仅从账号实际完成 levels 生成每套站位的加成。训练自动替补和球员修复仍按坐标槽位重映射，玩家 ID 变化不改变阵型。

## V2.1 实际比赛接入

- 进场时按 opening.positionPreset 选择对应研究；比分切换计划时一起切换对应站位加成，未绑定站位无加成。
- Spatial player profile 的十二研究指标按 `1 + 完成等级 / 100` 乘相应情境评分，门将不应用外场研究。
- 终结另接正式射门入口：普通射门用 finishing、空中终结用 aerialFinishing、远射用 longShot；远射决策能力也接 longShot。点球和直接任意球不额外获得这些研究。
- 不改永久球员卡基础属性，也不将能力百分比当作事件成功率百分点；原空间、体能、角色适应和概率限制继续有效。
- 正在进行的比赛使用其开赛快照；新成果用于后续比赛。
