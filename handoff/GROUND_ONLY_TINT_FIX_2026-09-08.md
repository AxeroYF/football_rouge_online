# 领地填色仅作用地面 · 2026-09-08

用户反馈上一轮增加 Leaflet 地块透明度会把下层 Three 建筑一起染色。本轮修复根因：

- atlas／relief 使用地形材质专用归属纹理，保留整块玩家色（0.38）及原豪门色强度。纹理按地图多边形绘制，随玩家颜色、换主和迷雾刷新；不写真实存档。
- 上层 Leaflet 仅保留边界与点击区域，正常、悬浮、选中、争夺及移动目标都不再填色覆盖模型。
- 建筑、树木、远征和球探不使用该地形材质；地形开关、缩放 LOD 与雪线兼容。释放地图时销毁纹理。
- 保留上轮可建造设施单行布局和图标＋数量按钮。

验证：完整 npm run check 808 次（74＋589＋145），0 失败；27 项地图专项通过；11 项隔离浏览器检查通过，无 shader／资源错误，七类 GLB 加载、模型点击、迷雾与选中态正常。

独立测试账号切换红／蓝领地颜色：131,129 个背景像素发生明显变化；21,451 个建筑内部像素与 232 个远征队不透明像素差值均为 0。掩膜排除透明轮廓抗锯齿，避免把背景变化算作模型染色。

复现：node scripts/review-ground-tint.mjs，然后 python scripts/check-ground-tint-pixels.py。前者只启动独立临时测试服务；截图与报告在 outputs/ground-tint-review/，完整检查在 outputs/ground-tint-check.txt。

已更新入口缓存版本。纯前端，用户 Ctrl+F5 即可。没有操作用户原服务／真实存档，未提交、推送、打包或部署。
