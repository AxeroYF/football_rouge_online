# 豪门挑战两级页面 · 2026-09-09

用户要求豪门挑战先按分级展示 18 队队徽，再点击进入阵容和挑战详情。

- 顶部“豪门挑战”默认打开目录页。按既有五档奖励/实力展示 I–V 档；每档显示能力区间、胜利球迷奖励。
- 使用 `assets/club-badges/` 的真实队徽，展示队名和 +5 首发平均能力；同档按能力降序。当前五档数量 1/6/5/4/2。
- 点击球队进入独立详情页，移除左侧长列表；展示队徽、名称、阵型、打法、11 人首发、奖励和挑战按钮。
- 详情页左上返回目录，保留目录滚动位置；直接从地图豪门按钮进入时仍可打开指定队详情。
- 直播/战报关闭后返回此前目录或详情；待领球员奖励和比赛状态在两级页面均可访问。
- 目录和详情分别滚动，手机目录为每行三枚队徽；详情单列。使用同步队徽解码避免轮询重绘时短暂空白；尤文、热刺的深色单色队徽在深色界面转为白色。
- 修改仅涉及前端展示与 UI 验收脚本，没有修改费用、奖励分档、比赛结算或正式玩家存档。

关键文件：`client/elite/elite-controller.js`、`styles/elite.css`、`app.js`、`index.html`。
