## 2026-08-01 V1 / V2 全量对照结论

- 完整性：30,000/30,000 场，V2 5,400,000/5,400,000 条控球链，500/500 场诊断样本。
- 节奏：V1 3.091 球、3.240 xG；V2 3.054 预期进球、3.057 链进球，整体标尺正确。
- 漏斗：组织 71.30% → 推进 57.66% → 最后三区 54.53% → 机会 43.72% → 射门进球率 17.33%；9.80% 控球到达射门。
- 断球角色：后卫 52.99%、中场 36.88%、前锋 3.55%、门将 4.66%、非受迫失误 1.92%；区域抢断逻辑有效。
- 最大结构问题：静态站位贯穿整条链。`4-2-3-1` 控球率 56.43%，但禁区存在感仅 0.199、V2 xG 1.267；`3-5-2` V2 xG 1.684。
- 阵型 V1/V2 排名相关性为 -0.438，说明动态前插未实现前不应通过固定倍率平衡阵型。
- 心态方向基本正确；打法尚未完整消费 `directness` 和 `counterAttack`。粗野比赛没有犯规牌成本，控球/反击/长传排序暂非最终结论。
- 接下来的实现顺序严格为：动态无球移动 → 直传/长传 → 反击链 → 比赛状态与体能 → 卡牌系统 → 环境事件。
