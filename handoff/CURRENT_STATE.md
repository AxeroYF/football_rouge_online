## 2. S4 球员池与后台

- 正式 S4 池约 550 人，按门将、后场、中场、前场分池，并包含用户补充校正的退役知名球员。
- 用户已经校正中文名、俱乐部、国籍和部分能力值，正式运行由 `versus/player-pool-s4-generated.js` 等生成数据接入。
- 管理后台可编辑球员姓名、主/副位置、俱乐部、国家队、身高、能力值和评级。
- 主位置和副位置允许选择完整位置集合。
- 后台支持搜索并向指定玩家发放指定球员、指定强化等级和数量的球员卡。

## 3. S4 所有权与球员卡

- 非传奇球员存在全服唯一所有权；传奇球员允许重复获取。
- 同一玩家可以拥有多张同名卡，大名单默认使用同名最高强化卡。
- 持有非传奇所有权时必须至少保有一张该球员卡；卖出或回收最后一张时同步处理所有权。
- 支持单卡交易/挂牌、所有权交易/挂牌、所有权返还和低等级单卡解约。
- 外部交易获得的 +3 及以上单卡在符合规则时不占 33 人名单额度。
- 新版球员卡突出位置、能力、姓名、俱乐部/国家队、特性和强化角标；强化等级按淡紫、金色、红底金字分层。

## 6. 战术板和比赛核心

- 战术板采用左侧球场、右侧三列替补席布局，球场有中线、禁区和合理位置识别区域。
- 球员磁贴使用 S4 金属深色视觉，显示强化角标、位置、姓名、能力和体力进度条。
- 主力与替补支持双向拖动；拖动时源位置磁贴消失，替补列表自动补位。
- 支持三套实时保存站位，开局/平局、领先、落后分别选择站位、比赛思路和战术打法。

- 模拟核心会分析各线高度、线距、中场间距、防线深度和阵型结构，并影响短传、长传、高压、低位防守等战术适配。

## 7. YDL 特性系统

- YDL 后台、强化三选一候选池和比赛运行时只保留以下 14 张特性卡：打点激素、避雷针、都是哥们、因凡蒂诺救救我、反向晴天娃娃、本质大心脏、变色龙、跳水王子、铁血蓝白、996、借过一下、全能战士、一夫当关、普拉蒂尼是我爹。
- 其他旧特性不再出现在 YDL 后台，也不能被 YDL 强化流程选中；好友十一人制模式原有特性目录未被误删。
- `chemistryAdjustedLineup()` 会把代表强化卡的全部 `traitIds` 传入比赛阵容。+5 卡可带一张强化特性，+8 卡可带两张，所有已绑定特性同时生效。
- 传奇球员的原生 `legendAbility` 与强化获得的 `traits` 是两条独立链路，不会相互覆盖；传奇升到 +5/+8 后可同时拥有原生传奇能力和一至两张强化特性。
- 已接入的规则：
  - 打点激素：有效身高 +20cm、开放中锋熟悉位置、头球与弹跳 +5。
  - 避雷针：球队免受雷击事件；只有一方拥有时雷击转向另一方，双方都有时本次雷击取消。
  - 都是哥们：该球员与相邻队友按 100 默契参与比赛计算。
  - 因凡蒂诺救救我：黑哨事件中的阿根廷球员数量按至少 11 人计算。
  - 反向晴天娃娃：雨、暴雨或雪天时全能力乘以 1.1。
  - 本质大心脏：比赛第 75 分钟起全能力乘以 1.1。
  - 变色龙：在国家队和俱乐部两个类别中分别作为通配球员，优先补入当前人数最多的可用羁绊。
  - 跳水王子：制造犯规与点球概率提高；失败时存在吃黄牌概率。
  - 铁血蓝白：球队采用“粗野比赛”思路时全能力乘以 1.05。
  - 996：比赛体力固定为 90。
  - 借过一下：速度、加速、盘带、传中和无球能力提高，并开放左右边锋熟悉位置。
  - 全能战士：除门将外的全部位置视为适配。
  - 一夫当关：保证扑出对手本场第一次点球，含常规比赛和点球大战。
  - 普拉蒂尼是我爹：持卡球员本人免疫红牌；不对全队生效。
- 后台仍可编辑这 14 张卡的名称、说明、适用位置和规则 JSON，覆盖数据保存在 `data/ydl-content-overrides.json`。

## 8. 国家队与俱乐部羁绊

- 正式 S4 球员池中人数不少于 10 人的组织才会生成羁绊资格。
- 国家队共 10 个：西班牙、法国、英格兰、德国、巴西、意大利、葡萄牙、阿根廷、荷兰、比利时。
- 俱乐部共 20 家：皇家马德里、巴塞罗那、阿森纳、AC米兰、拜仁慕尼黑、曼城、利物浦、马德里竞技、曼联、巴黎圣日耳曼、国际米兰、尤文图斯、那不勒斯、纽卡斯尔联、托特纳姆热刺、切尔西、阿斯顿维拉、多特蒙德、加拉塔萨雷、利雅得新月。
- 场上 11 人中有至少 5 人来自同一合格国家队或俱乐部时触发；加成曲线为 5人 +1%、6人 +1.5%、7人 +2%、8人 +2.5%、9人 +3%、10人 +4%、11人 +5%。
- 加成只作用于构成该羁绊的球员。国家队与俱乐部羁绊独立计算、可以同时生效；同一球员同时属于两条羁绊时两部分加成相加。
- 每个类别只采用当前人数最多的一条羁绊；人数相同时优先采用正式球员池人数更多的组织，再按名称稳定排序。
- 战术板左上角实时显示“羁绊已可用”以及具体状态，例如“西班牙羁绊 5/11 +1%”；国家队与俱乐部双羁绊会同时显示。
- 比赛前的体力红线自动轮换按实际出场 11 人重新计算羁绊，不会沿用被换下球员的资格。

## 11. 本机与 iPad 局域网测试

默认 `npm run demo` 监听 `127.0.0.1:4310`，只能本机访问。iPad 测试必须改为监听所有网卡：

```powershell
cd D:\Project\game_test\.worktrees\s4
$env:VERSUS_HOST="0.0.0.0"
$env:DEVTOOL_PORT="4310"
npm run demo
```

本机当前以太网 IPv4 为 `192.168.31.19`。当电脑和 iPad 在同一局域网时，iPad Safari 使用：

- 玩家端：`http://192.168.31.19:4310/versus/`
- 管理后台：`http://192.168.31.19:4310/admin/`
- 强化测试 Demo：`http://192.168.31.19:4310/versus/s4-enhancement-demo.html`

如果无法连接：

1. 确认 iPad 与电脑连接同一路由器，且 iPad 地址也是 `192.168.31.x`。
2. 保持 PowerShell 服务窗口运行，确认没有 `EADDRINUSE`。
3. Windows 防火墙首次询问时允许 Node.js 访问“专用网络”。
4. 必要时以管理员身份执行：

```powershell
New-NetFirewallRule -DisplayName "YDL S4 LAN 4310" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 4310 -Profile Private
```

5. 若路由器开启 AP/客户端隔离，即使同一 Wi-Fi 也无法互访，需要关闭隔离或改用可信的公网隧道。

停止服务：回到 PowerShell 窗口按 `Ctrl+C`。服务端代码修改后重新执行启动命令。
