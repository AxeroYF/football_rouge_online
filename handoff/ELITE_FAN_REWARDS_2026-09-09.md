# 豪门球迷奖励分档 · 2026-09-09

用户指出豪门实力差异不应统一奖励。新挑战改为按实际 +5 首发的展示平均能力分档：

| 平均能力 | 胜利球迷 | 当前球队 |
|---|---:|---|
| >= 99 | 2,000 | 皇家马德里 |
| >= 97 且 < 99 | 1,600 | AC米兰、拜仁、曼联、巴塞罗那、国际米兰、阿森纳 |
| >= 95 且 < 97 | 1,200 | 尤文图斯、切尔西、曼城、巴黎圣日耳曼、利物浦 |
| >= 92 且 < 95 | 900 | 马德里竞技、本菲卡、多特蒙德、那不勒斯 |
| < 92 | 600 | 纽卡斯尔联、托特纳姆热刺 |

配置：`shared/config/elite-clubs.mjs` 的 `ELITE_FAN_TIERS` / `eliteFanReward()`。以游戏展示的一位小数平均值划档，球员库变化后新挑战跟随真实首发重新计算。

服务端开始比赛时保存 `fanReward`，胜利按该快照发放；赛中改卡库或重启不会改变本场已展示的奖励。旧存档没有 `fanReward` 的进行中比赛继续兑现原先的 1,000 球迷；已完成比赛不追溯修改。

列表和详细规则均显示各队奖励；比赛进行中显示本场锁定奖励；结算展示实际到账数。接口 `rules.fans` 为所选球队动态值，兼容旧客户端；球队各有 `fans`。

挑战费仍为 5,000 金币，基础球员三选一、失败 20 分钟休整等规则继续生效。

验证：18 项豪门专项和隔离桌面/手机浏览器验收；覆盖全部档位边界、18 队分组、不同球队实际到账、赛中卡库变化、重启、旧比赛兑现、重复结算和保存失败回滚。前一轮全量 1,043 项通过，本轮针对奖励改动执行专项复验。
