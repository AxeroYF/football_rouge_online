## 当前新增：森林、河流与雪线

- 正式地图与预览默认加载自然地貌，不改动大陆厚度 1.1、35° 倾角或现有玩法。
- 河流采用 Natural Earth 1:10m rivers/lake centerlines，按真实坐标转换并裁到地图地块；欧洲 246 段、南美洲 205 段，合并 4 个渲染批次。来源：https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-rivers-lake-centerlines/ （public domain）。
- 森林是风格化气候区示意，不是精确土地覆盖图。2041 处锚点经城市/海岸/高程排除，再在运行时避开河道、海面、孔洞和雪区，生成 8508 棵实例树，按 54 个空间块剔除；斯瓦尔巴不放树。
- 森林在主图约 ×2 到 ×5.5 之间渐显，小河约 ×3 到 ×7.5 渐显，避免开关式跳变；树不参与阴影投射，不新增大批动态光源。
- 雪线来自本地 Terrarium DEM z8/z9 数值缓存，使用真实纬度与海拔的固定风格化阈值，并非实时气象积雪。南美洲先还原真实坐标采样，避免错用游戏显示纬度。
- 雪盖以 3 张单通道数值纹理参与现有地形材质，保留 DEM 山体明暗；没有另铺白色多边形，没有修改或生成整套地形图片。
- 资源为 assets/data/map-environment.json，约 1.27 MB，包含压缩数字雪盖、树丛锚点、河流坐标与来源校验值；异步加载失败不阻断游戏，显示提示并支持重试。
- 构建：先将 Natural Earth 官方仓库 geojson/ne_10m_rivers_lake_centerlines.geojson 放到 .cache/map-environment/ 同名文件，然后运行 npm run build:map-environment。构建器只读已有 DEM 缓存，不下载 DEM；源码 URL 和 SHA256 写在生成资源 source 中。

## 实现方式

- Three.js 实际绘制海面、浅海、陆地顶面、真实侧壁与光影，加载现有统一 z3–z7 DEM 纹理。
- Leaflet 继续承担业务叠加与输入协调：领土归属/悬停/选择/挑战边界、建筑、战棋、海路、天气、城市、国境和小地图。
- 主地图使用沿南北方向压缩 cos(35°) 的 Web Mercator CRS；Three 正交相机从主图真实容器中心、缩放和尺寸计算。
- 各业务覆盖物、点击逆投影和地图地形共用同一地表平面，不做 CSS 透视，不在父级重复平移 WebGL 画布。
- 正式地图固定北向与 35° 倾角，不开放预览右键旋转；避免业务覆盖物和点击投影脱离当前固定 CRS。最大倍率仍 ×16。
- Three 模式关闭 Leaflet CSS 缩放动画，保留连续鼠标锚点惯性缩放、平移、键盘和小地图联动；兼容模式保留原 CSS 动画。
- 主要城市、天气、国境线继续默认关闭；省级轮廓在业务层以低透明度显示。
- Three 模式的中立地块不再涂不透明底色；俱乐部与玩家领土使用实时状态的半透明色层。兼容地图保留旧式底色。

## 海岸修复

- 问题是独立半透明矩形沿短线段交叠，海岸转角没有连接，导致放射状叠色。
- 新浅海带是带圆连接/端帽的覆盖并集；每层独立模板缓冲位，保证同一像素每层只叠色一次。
- 地形只在陆地模板区域绘制，避免带透明边缘的瓦片覆盖海面或侧壁。
- 海岸侧壁与顶面都用投影坐标单位简化，不在斯瓦尔巴使用被纬度放大的度数容差。
- 两层浅海和陆地模板使用互不冲突的位；renderer 必须启用 stencil: true。

## 性能与生命周期

- 只在视野、纹理或页面恢复变化时请求绘制；纹理完成不会自发产生每 100ms 的空转循环。
- 视野加载限流 100ms，并发 6，最多规划 100 张细节瓦片，缓存上限 160；保留基础纹理并释放淘汰资源。
- WebGL 上下文丢失显示恢复/兼容提示；页面恢复重新检查视野，销毁时清理监听、帧、定时器、纹理和 WebGL 资源。
- 山脉仍为烘焙 DEM 阴影，不是真实逐点起伏的高程网格；陆地侧壁是真实三维几何。
