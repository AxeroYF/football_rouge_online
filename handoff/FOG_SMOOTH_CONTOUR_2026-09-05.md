# 迷雾轮廓与可见板块交互（smooth-fog v5）

用户最新明确：沿多块领地分布连接形成视野，只把长直边和转角圆滑化，不要把整个范围拟合成圆或椭圆。范围中间海域内的岛屿保持可见；所有可见板块支持悬浮信息及点击详情。本规则取代 round-fog v4。

## 实现

- `shared/map/fog-spatial.mjs`：用领地顶点凸包确定原始连接轮廓，边中点适度外弯，再用切线连续的三次贝塞尔曲线连接。曲率受局部尺度约束，狭长岛链保持狭长。自适应离散曲线供服务端、主地图、小地图和延迟加载共用，平移不重新计算。
- 曲线围合区作为真实可见区域，海面和中间岛屿都显露；真实法罗群岛数据验证了可见 ID、探索、相遇和地形加载。临时海岸预览仍使用原来的登陆点/航线及取消回收规则。
- 交互和服务端可见 ID 同时计入 `FOG_RULES.feather` 边缘宽度，局部显露的板块能获得情报。远处仍被遮挡的板块及同一大省中未进入视野的部分不能通过鼠标查看。
- 新增 `client/map/territory-interaction.js`：在 mouseover 和 mousemove 上持续检查视野，点击使用相同判定。新增发现时恢复 Canvas 交互开关和 SVG 命中目标；隐藏时收回交互。普通移动仅更新提示位置，不反复重绘板块。
- 一个独立提示框作为地图容器的直接子节点，z-index 710，高于屏幕迷雾 630，不受 Leaflet mapPane 的层叠上下文遮挡；靠边限制在视口内，拖动/缩放/移出地图时关闭，卸载清理事件。
- `app.js` 接入新交互控制器；每次应用世界快照同步刷新板块交互，防止地图开雾后沿用隐藏状态。`territory-controller.js` 仍负责选中详情和情报请求。
- app、相关入口及 CSS 缓存标记为 `20260905-smooth-fog-v5`。保留 25×、屏幕固定遮罩、渐变、小地图受限取景、地形延迟创建、旧设施素材及玩家配色。
