# YDL S4 Offline v1.1（Windows x64）

这是仅供朋友间使用的 YDL 单机存档。它不连接线上服务器，也不包含好友对战、计算节点市场或线上运营配置。

## 使用

1. 将 ZIP 完整解压到本地目录，不要直接在压缩包预览窗口里运行。
2. 双击 `YDL S4 Offline.exe` 打开启动器。
3. 启动服务前可选择是否解除球员 99 数值上限；开启后可选择超限部分按 `100%`、`50%` 或 `30%` 参与 V2.1 模拟。
4. 点击“启动服务”。首次启动会自动初始化离线存档和球员图片。
5. 显示“离线服务运行中”后，点击“进入游戏”或“进入后台”。
6. 保持启动器开启；关闭启动器会停止由它启动的本地服务。
7. 可选择任意球队进入，其他球队由 AI 接管；返回球队选择页后可切换球队。
8. 本地后台密码：`ydl-offline`

游戏数据保存在：

`%LOCALAPPDATA%\YDL S4 Offline\`

备份单机进度时，请先关闭启动窗口，再完整复制该文件夹。`打开存档目录.cmd` 可以直接打开此位置。


## V2.1 属性上限

- 默认关闭解锁，行为与原版一致，球员属性最高按 99 显示和计算。
- 开启后，强化、阵容化学反应、特性和羁绊产生的真实 26 项属性可以显示为 100 以上。
- `100%`：超过 99 的部分全部进入比赛引擎。
- `50%`：超过 99 的部分按一半进入比赛引擎。
- `30%`：超过 99 的部分按三成进入比赛引擎。
- 修改规则前需先停止服务；设置保存在 `%LOCALAPPDATA%\YDL S4 Offline\launcher-settings.ini`。
## 兼容性

- 支持 64 位 Windows 10 与 Windows 11。
- 已内置 Node.js、Excel 导入导出和图片转 WebP 所需依赖，无需安装开发环境。
- 服务只监听本机 `127.0.0.1`，局域网其他设备无法访问。
- 原玩家凭据、密码摘要、后台操作历史、纪律记录、计算节点记录和私密服务器配置均未包含。

`启动 YDL S4 Offline.cmd` 是兼容入口，同样会打开 GUI 启动器。

若启动失败，可在启动器中点击“查看日志”，或运行 `检测离线版.cmd` 检查包内文件和运行依赖。
