# 黄狗风云窗口标准

项目固定使用三套窗口：

1. **标准窗口**：球队管理、比赛电视台、YOOGLE 搜索页。最大宽度 1600px，地图工作区边距 12px，手机边距 8px。
2. **加宽窗口**：战术板、强化。最大宽度 2180px，边距 16px，保留战术板现有三栏独立滚动布局。
3. **小型窗口**：26项球员数值详情等档案、确认窗口，以及已接入小窗口管理器的背包（背包内容有独立布局约束）。桌面标准尺寸 1180×820px，桌面遮罩边距 24px；可用空间不足时自适应，手机全屏。

标准窗口和加宽窗口共用顶层展示窗口管理器，同一时间只打开一个，支持 Esc、地图压暗和焦点恢复。小型窗口作为模态层叠加在顶层窗口内部。


## 统一外观（club-ui v1）

共享外观在 `styles/ui-theme.css`，通过 `html[data-ui-theme="club"]` 生效，必须在各模块 CSS 后加载。普通窗口和工具面板使用深绿灰，主操作暖金底深字，次操作深底；同级关闭按钮 36px，普通控件 40px，紧凑控件 32px。页面标题通常 22px，上下文侧栏 18px；控件/面板/窗口圆角 8/12/16px。

训练和球探保留现有左上角上下文侧栏，选人/结果面板保留已适配的内容尺寸；本次统一外观不改变窗口管理和滚动行为。卡牌、球场、地形与演出继续使用专用素材和内容颜色。新组件应优先使用 --ui-* 变量；不要给普通模块面板增加另一整套底色。

URL 参数 `ui=legacy` 可使用旧外观，不写入用户状态。具体备份、范围和验证记录见 `handoff/UI_UNIFIED_2026-09-05.md`。


## 金币与任务信息（2026-09-05）

玩家界面中的金币金额统一使用 client/ui/currency.js 的 goldAmountMarkup；独立图标使用 goldIconMarkup 或同一个 assets/ui/gold-coin.svg。图案固定为普通硬币堆，不使用足球、货币 Emoji 或各模块自行画的替代图。图标和数字保持一行，单位名称留在可访问标签和说明文字中。建造按钮只显示图标＋费用，不加“建造”副行。

施工、训练和球探通知放在同一个右上任务区。施工完成等待服务端确认，完成提示短暂显示后收起；不要重新增加常驻探索统计 HUD。


## 卡片效果小幅保留（2026-09-05）

已撤回 card-experience v1 全面改版，保持原卡框和合卡 UI。三选一仅沿用新翻牌动作；有卡画卡片可使用独立阴影层和单次高光，必须保持原头像坐标和卡片尺寸。球探轮询不得重复触发翻牌。


## 远征队上下文面板（2026-09-07）

用户指定的远征队信息面板与训练／球探一样位于地图左上角，不使用全屏模态。宽度最多 366px；名单区独立滚动，操作固定在底部。沿用 --ui-* 变量及 18px 侧栏标题，打开其他地图侧栏时互斥；点击单位仅查看，移动通过显式按钮启动。
