适配覆盖直接获卡、三选一、指定球员礼包，以及原有批量开包的选择阶段和最终汇总：

- 暗色开包舞台与 16 条 CSS 流星背景。

- 手机竖屏候选区域可滚动；指定球员池最多同时对前六张播放入场；批量结果维持原有每页 20 张。

价格、概率、球员池、卡数、强化等级、所有权、名单限制和服务端奖励逻辑没有因本次接入而变更。旧装饰礼包继续走原兼容展示。

## 流畅度与请求处理

`pack-opening.js` 管理有限的图片等待、入场定时器和一次 RAF，不增加持续运行的 JavaScript 动画循环。流星由 CSS 实现；页面隐藏时暂停，系统要求减弱动画时关闭位移动画并隐藏流星。关闭或替换对话框、退出账号时移除监听器并取消定时任务，过期的解码回调不再操作界面。

领取期间阻止重复提交。失败时恢复原候选节点和按钮，不重新抽取、不重播入场；成功后补丁更新选中卡数据。常规页面同步不替换相同 offer 的开包节点，已完成的展示也不会因同步立即消失。请求返回时检查账号及对话框身份；用户关闭窗口后不重新弹出，旧账号的响应不合并进新账号状态。

样式限定在 `#league-dialog-overlay.rougelite-pack-overlay`，避免覆盖商店、背包及其他弹窗；同时避免桌面浅色主题把开包舞台改成白底。
