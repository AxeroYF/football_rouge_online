# YFFM1 视觉升级评估 · 2026-11-10

方向：电脑端优先、兼顾手机。依据为当前源码及隔离账号的实际界面，桌面观察宽度为 1280px，另检查 390×844 的手机视口。以下为设计建议，不代表已实施的全面改版。

## 推荐

以“专业经理桌面”作为日常界面的统一基础：紧凑且有分组的导航、清楚的中文层级、稳定的数据表格、低干扰背景，以及突出的下一场比赛。比赛中心采用转播视觉，开包/强化/夺冠保留仪式感，俱乐部与荣誉室可以采用年鉴式排版。

现有盾形卡框、等级配色、球员肖像和开包素材有辨识度，优先保留并统一周边信息层。大面积重做素材的收益低于改善高频操作和视觉层级。

## 当前问题与对应方向

| 观察 | 建议 |
| --- | --- |
| 登录后的入口页仍以“选出你的十一人”为主文案，混合联赛、快速比赛、锦标赛与房间入口 | 已有球队优先进入经理首页；首次进入突出建队；其他比赛入口按产品范围明确归类 |
| 16 个同级联赛导航按钮占据长侧栏，部分功能需要滚动寻找 | 按俱乐部、球队、赛事、经营组织；保留高频页直达，减少重复跳转 |
| 总览首屏主要是积分榜、日报与搜索，下一场比赛不够突出 | 下一场对手、时间、阵容可用性与备战动作放到首屏；积分榜与赛果作为支持信息 |
| 1280px 战术页实测文档宽度为 1540px，横向滚动才能看到部分内容 | 优先保证球场和当前操作区；替补席可折叠，细节战术采用抽屉或阶段切换；不靠缩小字号硬塞 |
| 桌面浅色为蓝白、手机端为深绿黄，按钮、阴影和卡面视觉强度差异较大 | 建立统一品牌主色与明暗主题规则；操作色、危险色、球员等级色各司其职 |
| 手机背包页标题、操作与筛选占据大半首屏 | 合并标题信息、收起低频筛选；首屏尽早展示可操作的球员卡 |
| 开包动效因系统减弱动画而静默关闭 | 已补统一设置与开包快捷选项，说明系统状态，允许手动开启 |

## 三种风格的适用范围

“专业经理桌面”适合战术、阵容、市场、积分榜和长期操作，是主推荐方向。

“比赛日转播”以比赛、比分和球队对抗为焦点，适合直播、赛前与赛后页面。全站使用会挤占表格及管理操作空间。

“俱乐部年鉴”强调队徽、队史、荣誉与赛季故事，适合俱乐部首页和荣誉室。日常强化、交易与战术页面仍需要更紧凑的操作界面。

## 实施顺序

1. 经理首页、全局导航、字体/颜色/间距及基础控件。先用总览、战术、背包三页验证同一套规则。
2. 战术板重排、球员卡图文两种浏览方式、统一筛选和球员详情。保留既有自动保存、节点复用及选中状态。
3. 直播比分条、关键事件、战报摘要、开包与强化反馈，统一其视觉语言和动画设置。
4. 俱乐部/荣誉室以及手机交互细节收尾。

验收应同时检查 1280、1440、1920 的桌面布局和 390px 手机布局：桌面主体无横向滚动，常用文字清晰可读，长球员名有完整信息入口；相同操作不增加无谓点击；高频刷新保留滚动、焦点、阵容草稿与卡片选中状态。动画支持减弱偏好，并针对真实设备测量流畅度，避免把单次截图或桌面手机视口当作手机性能结论。
