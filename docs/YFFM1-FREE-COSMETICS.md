# 国家队与俱乐部装饰免费开放

日期：2026-11-04。本次更改不涉及比赛数值、球员卡、普通市场价格或既有金币余额。

## 当前规则

- 新老玩家均可直接使用完整装饰目录：当前 34 款国家队、51 款俱乐部装饰。
- 在“背包 → 道具”佩戴、切换和取消，两个类别独立；既有佩戴选择保留。
- 权限由统一目录提供，未来账号同样获得完整目录；不为每个账号重复写入 85 份库存。历史库存数量保留，但前台按可用款式显示。
- 商店及后台新发放目录移除国家队/俱乐部徽章礼包，旧购买请求会被后端拒绝且不会扣款。
- 移除装饰交易页面与挂牌入口；后端也拒绝挂牌与成交请求。球员单卡、所有权、定向卡牌交换保持原规则。
- 未开启或待选择的旧徽章礼包仍可完成原流程，避免历史存档卡住；不再产生新的商店购买。

## 旧挂牌迁移

加载 JSON 或分片存档时，若发现活跃装饰挂牌：

1. 创建 `pre-free-cosmetics-v1.json`，分片模式为对应 `.manifest.json` 快照。
2. 将挂牌标记为取消，记录 `closedReason:free-cosmetics`。
3. 返还托管装饰；原挂牌曾卸下的装饰，在对应槽位没有新选择时恢复佩戴。
4. 保存变更。后续重启不会再次返还。

历史已成交记录、其他资产挂牌、原金币和流水不因本次迁移重算。没有执行历史消费退款或调整余额。
