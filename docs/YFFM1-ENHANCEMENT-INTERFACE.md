# 合卡新版与经典界面

2026-11-14

游戏设置 → 合卡界面 → 合卡界面版本，可选择“新版界面”或“经典界面”。默认新版，偏好保存在当前浏览器；刷新后仍保留。切换时保留当前选卡、保护选项和待处理结果。

新版使用覆盖舞台与仓库的统一动态背景，保留桌面左侧导航。放大的两张球员卡左右排列，移除主卡/副卡标签、槽位边框和常驻说明，中心保留成功率、能力成长与必要费用。背景有缓慢移动的光束、呼吸光环及上升粒子。

仓库默认收在底部；桌面鼠标移入底部时滑出，移出后延迟收起，手机端点击底部把手展开。展开时舞台上移，卡片适当缩放以留出空间。仓库保留搜索、筛选、排序、拖放和批量合卡；输入与拖拽期间不会误收起，支持 Escape 收起及键盘打开，收起内容不接受焦点。

待合卡悬停或键盘聚焦时上浮 10px、贴合盾形轮廓发出柔光，并扫过一道高光。合成过程中停用悬停动效，关闭界面动画时仅保留静态高亮。

动效顺序为选卡入场、双卡蓄力汇聚、中心柔光、权威结果揭晓。成功卡有入场、背光和扫光，高等级使用金色背光；失败显示保级或降级，不使用成功庆祝。结果可通过明确按钮放回仓库；需要绑定特性时先完成选择，支持稍后绑定及刷新恢复。

“界面动画”控制新版合卡动效，跟随系统减弱动画、开启、关闭均可。跳过只结束演出等待，不取消或再次发出合成请求。切换页面、后台化及切换界面时停止等待，避免返回后补播。开包动画仍由独立设置控制。

两种布局共用现有卡片、成功率、保卡费用、挂牌/锚点/X卡限制、特性和请求幂等键，不改变服务端合成规则。合成中阻止重新选卡、移除卡片和重复提交。特性选择使用原接口，失败时恢复按钮供重试。

## 实现入口

- `versus/public/enhancement-interface.js`：从经典的同一份权威标记生成新版布局、底部仓库控制，以及可跳过、可中断的演出等待。
- `versus/public/enhancement-interface.css`：仅对新版生效的舞台、仓库和动效样式。
- `versus/public/game-settings.js`：`enhancementInterface` 设置，值为 `modern` / `classic`。
- `versus/public/app.js`：共用合卡请求、结果回仓和新版特性选择。

## 设计参考

参考 [EA FC Mobile 官方培养说明](https://help.ea.com/en/articles/ea-sports-fc/fc-mobile/how-to-rank-up-players/)的选人、培养与能力信息层次，以及 [eFootball 官方 Dream Team 说明](https://www.konami.com/efootball/en-us/page/dreamteam)中的 Player Fusion 主卡成长概念。舞台、双卡汇聚和结果动效为本项目实现，未复制其他游戏素材，也不引入其养成规则。
