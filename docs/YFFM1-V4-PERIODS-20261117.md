# V4 第四阶段：半场、换边、补时与比赛节奏

独立版本 `4.0.0-prototype.4`。正式 V3.3、预测 V1/24 样本、真实存档和赛季业务没有接入或修改。启动 `npm run dev:v4`，打开 http://127.0.0.1:4314，刷新已有页面。

## 比赛时间与规则

输入新增 `format: full | clip`。5400 秒默认完整比赛，其余默认片段；完整比赛的 duration 是两个半场的常规时间总和。完整90分钟包含两个45分钟半场、中场15分钟及各半场补时。专项“半场与换边”可把所选短时长分成两半，中场缩为6秒，便于观察。中场时间是模拟时间，不要求用户现实等待15分钟。

引擎以固定0.2秒推进，`state.time` 是含中场休息的连续回放时间；`clock.elapsed` 是本半场时间。下半场显示从45:00开始，补时显示45+或90+。双方身份、比分、纪律和随机流保持不变，攻防坐标统一反转；下半场由另一方开球。球门、乌龙球、越位线、禁区、定位球、封线与门将扑救都读取当前方向，球队编号不再等同于物理半场。

休息期间不移动、不决策、不抽随机数，也不消耗体能；再次开球前恢复少量体能（90分钟比赛最多2点）。普通重启在半场结束时取消。加时赛、点球大战、额外换人没有实现。

补时台账分别保存两半场的实际损失和原因。常规界外球、球门球、角球及任意球准备计入死球时间；庆祝、纪律处理、点球额外准备只按已经流逝的额外部分计入补时。常规时间结束时把已损失秒数向上取整为整分钟，公布最低补时；此后新损失继续增加本半场补时，不减去已公布时间。没有“每半场固定补三分钟”。

当前重启准备采用固定工程参数：界外球18秒、球门球/角球30秒、直接任意球28秒、间接任意球24秒；点球正常准备30秒加额外20秒，进球后正常开球准备20秒加庆祝30秒。黄牌额外12秒，红牌25秒。开场和下半场首次开球不等待这段时间。这些不是 IFAB 强制等待秒数，也未实现拖延判罚、伤停和VAR。

到时有已判点球时延长至本次罚球完成，包括门将未控制的触球后轨迹；进球、出界、球停止、门将控制或其他球员触球后终止，不允许再补射或重新中圈开球。普通射门、任意球或进攻不享有额外一次进攻。门框碰撞仍未建模。

规则依据：[IFAB Law 7](https://www.theifab.com/laws/latest/the-duration-of-the-match/)、[Law 8](https://www.theifab.com/laws/latest/the-start-and-restart-of-play/)、[Law 14](https://www.theifab.com/laws/latest/the-penalty-kick/)。本实现是地面球原型的明确子集；没有声称覆盖全部裁判规则。

## 节奏与解释

此前几乎一接稳就再次传球，固定16场对照平均3525次传球，控球到下一次传射约0.56秒。现在接球后先控制并观察：无压迫时随战术直接性约2–3秒，近身受压允许至少0.8秒后提前出球；观察时只作小范围调整，主动带球必须进入后续决策。

带球价值比较空闲距离，安全传球比较线路到达时间和接应空间。门将不会反复选择无法执行的推进。地面传球球速和接球质量一起校准；无人接到的球在目标点后继续滚动并形成自由球，不在空中目标点凭空停止，也不把后续二点球记作成功传球。较长定位球准备时间形成实际死球节奏。

近身上抢有行动冷却；已有黄牌球员降低再次冒险上抢概率。严重程度抽样和犯规判定分开，明显进球机会要求更严格地检查方向、距离和实际保护人数。真实判定为第二黄牌、DOGSO或过度力量时仍正常罚下，没有按每场配额隐藏牌。

射门误差随能力、距离、压力和体能变化，解释事件保存能力、体能、疲劳误差、总误差及实际偏差。未直接指定进球、封顶最终比分或修改已发生赛果。

## 播放与检查点

播放器支持完整90分钟和缩短的双半场场景，共12场景。主计时显示比赛时钟，进度条是含中场休息的回放时间。新增半场状态、公布补时、换边箭头、下半场跳转、64倍速。保留可调速和射门/脱手关键片段慢放。

进度条终点使用实际完赛时间，包含补时和中场休息。跳回过去不会显示未来的换边、补时公告、比分或判罚。半场重排位置不插值成横跨球场的移动。中场不重复存储900秒相同帧；完整比赛每秒录制普通帧，同时保留实际触球帧，物理步长仍为0.2秒。

检查点保存时钟、各半场台账、待罚点球、休息剩余时间、控制观察计划和录制间隔，可在休息、补时、点球延长期间精确恢复。旧 prototype.1/2/3 实验检查点明确拒绝；不迁移正式存档。

## 统计与验证口径

固定四战术两两组合，每个种子16场。训练与独立验证种子分离，分别运行10分钟片段与真实推进的90分钟双半场比赛。90分钟比分分布来自终场结果，不拿短片段乘九代替。门槛是原型工程范围，不是实际联赛统计拟合。

整场指标为双方合计。传球成功为同队实际控制已发出的传球；首次接传球失误率为同队首次接触时未停稳的比例。二次黄牌计入黄牌，同时另计红牌。有效比赛占比为球进入比赛的时间除以常规时间加实际延长时间，中场900秒不在分母中。平均持球时长按控制事件到同一球员下一次传射计算；被抢断/犯规中断的控球不当作已完成释放样本。

工程门槛：传球成功70–90%、首次接球失误2–12%、总进球1.8–4、0球场次不超过25%、6球以上不超过15%；每场传球700–1300、犯规15–35、黄牌2–6、红牌不超过0.25；有效比赛占比50–75%，已释放控球平均1–4.5秒。

最终数据、源文件哈希、训练/验证种子、逐场统计见 `outputs/v4-periods-20261117/acceptance.json` 和四份 `calibration-*.json`。`iteration*` 保留失败校准记录，不代替最终验收。第三阶段备份和保护文件原始哈希位于 `outputs/v4-before-stage4-20261117/`。
