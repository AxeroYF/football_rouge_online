# 游戏设置 · 2026-11-10

顶部“游戏设置”在登录页、主模式及本地离线模式提供统一入口，包含：

| 分类 | 设置 |
| --- | --- |
| 显示与主题 | 电脑端浅色/深色；背包球员卡标准/紧凑；同名同强化卡片叠放 |
| 界面动画 | 跟随系统、开启、关闭；控制操作与比赛反馈 |
| 开包动画 | 跟随系统、开启、关闭 |
| 战术板辅助 | 场上球员磁贴/盾形卡、默契连线、羁绊增益、位置阴影 |
| 账号与安全 | 在线账号进入现有的修改密码流程 |

修改即时生效，自动保存到当前浏览器的 `yffm1_game_settings_v1`。首次读取兼容既有主题、开包动画键；保存时同步这些键。侧栏主题、背包显示、战术板辅助和开包窗口中的快捷开关均与统一设置同步。恢复默认设置只恢复这些个人偏好，不操作登录凭证或球队存档。浏览器禁止存储时，本次会话仍可使用，界面会说明没有保存成功。

电脑端主题仍沿用当前的 1051px 断点，手机端继续使用原深色样式。设置窗口支持内部滚动、键盘焦点循环、Esc 关闭及焦点返回入口。

## 基础界面动效 · 2026-11-13

“界面动画”独立于开包动画，默认跟随系统。覆盖按钮按压与悬停、页面切换淡入、弹窗入场、保存成功及提示反馈、直播比分跳动、进球/红黄牌/伤退/换人相关球员高亮、体力条变化和事件入场。关闭时立即取消正在播放的新反馈；系统偏好改变时同步生效。

切页按页面标识触发，同页轮询不重复淡入。直播以服务器比分和事件 ID 比较新变化，首次观赛、重新接入、切回前台不补播历史；同一响应重复刷新不会重复播放，最后一刻的进球仍可反馈。反馈不延迟比分、文字直播和结算。战术板磁贴的位置与拖拽逻辑、开包演出保持原有实现。

验证：`node scripts/run-tests.mjs ui-motion.test.js game-settings.test.js broadcast-presentation.test.js`，以及 `npm run build`。本机“游戏设置 → 界面动画 → 开启”后可检查切页、打开设置及 AI 对战；选择关闭后应立即停止对应过渡。测试截图保存在 `outputs/ui-motion/`。

## 日常操作反馈 · 2026-11-13

第一轮新增六组反馈，归“界面动画”管理：

- 请求状态：登录、AI 开赛、购买确认、市场挂牌/购买/撤单、交易发起、回收及部分经营表单显示“处理中”；同一待处理请求复用 Promise，页面局部刷新后继续保留按钮状态。失败恢复可操作状态，并显示可关闭、不会自动消失的错误提示；重新操作时清除旧错误。
- 资源变化：服务端数据先立即落到金币、大名单和库存显示，随后短暂展示增减数字。首次进入、相同快照、切换账号或返回后台页面不补播历史变化；购买礼包也会强调背包入口。
- 选卡入槽：强化主副卡槽在实际变更后高亮；交易选卡增加勾选标记和 `aria-pressed` 状态，选中反馈与原选卡规则共用同一数据。
- 换人落位：仅对发生站位、首发/替补身份、位置职责变化的球员做短暂边框反馈。拖动过程继续紧跟指针，反馈不修改磁贴 transform、站位或换人逻辑。
- 战术切换：预案标签、心态和原则控件在变更后高亮；雷达从旧轮廓向新轮廓过渡约 260ms，关闭动画时直接显示最终轮廓。雷达仍为静态阵容投影。
- 购买与交易结果：购买提示实际获得的礼包名称和数量，市场购买提示已获得球员；挂牌、撤单、报价与交易处理结果使用统一提示。业务响应为交易失败时显示失败提示，不显示交易达成；交易历史仅在新增或状态变化时高亮。

结果提示不阻塞下一次操作。关闭界面动画时仍显示处理状态、勾选、获得内容与错误信息；资源浮字、脉冲和轮廓过渡停止。开包、建队演出仍独立归“开包动画”控制。

源码入口：`versus/public/interaction-feedback.js`、`ui-motion.js` / `.css`；`app.js` 在业务请求、整页与局部渲染中挂接，`tactics-interface.js` 提供雷达过渡回调。

## 开包动画不出现的原因

本机浏览器实测 `(prefers-reduced-motion: reduce)` 为 `true`。原代码同时在 JS 和 CSS 中隐藏流星、跳过卡片动画，却没有玩家可见的状态说明。

现在默认“跟随系统”，但可在统一设置或开包窗口选择“开启”，仅覆盖开包演出的动画偏好。页面切到后台仍会暂停动画。切换偏好不会重置领取中的请求、恢复已领取卡片按钮或重抽候选；领取逻辑、概率及奖励不变。

相关回归：`node scripts/run-tests.mjs game-settings.test.js pack-opening.test.js player-card-shield.test.js s4-assets.test.js pack-market-performance.test.js`。浏览器使用独立临时存档验证，未修改真实账号。

本轮快速回归 61 个文件、511 项检查通过，255 个模块语法检查及构建通过。实际浏览器验证偏好刷新保留、主题切换、Esc 关闭后焦点返回入口；在系统减弱动画为 true 时，手动开启后 16 条流星正常运行，三张候选卡触发入场动画并可正常领取。手机端有响应式样式；本轮设置窗口的实际浏览器验收限于桌面尺寸。
