# 主教练系统设定汇总

> 当前状态：暂不进入主开发线，作为后续独立版本设计稿保留。

## 核心规则

- 教练拥有独立卡牌，等级为 S / A / B / C；全服唯一，同一教练不能被多个玩家同时持有。
- 单个玩家最多持有 3 张教练卡；教练卡不占球员大名单席位。
- 单个玩家最多签约 1 名主教练。签约后进入 30 场正式比赛合同，联赛和杯赛计数，友谊赛不计数。
- 签约时一次性支付金币，不按场发工资。签约费用：S 级 15000、A 级 12000、B 级 8000、C 级 5000。
- 到期前强行解雇需再次支付违约金，默认是签约费用的一半；近期正式比赛成绩越差，费用越低，近五场五连败时可免费解雇。
- 合同到期后未续约的教练自动回到背包；支持玩家设置自动续约。金币不足时合同结束、席位空缺。
- 未签约的教练卡每场正式比赛收取每张 500 金币保管费；无法支付时系统强制回收该卡。
- 拥有主教练的球队体力消耗速度降低 30%。

## 交易与获取

- 未执教的教练卡可以在传奇/强化卡市场挂牌交易；签约中的教练卡不可挂牌。
- 购买教练卡包获得教练卡，S 级基础爆率严格控制为 5%，其余等级上线前可继续平衡。
- 不发放重复教练卡；卡牌所有权转移时同步转移唯一占有关系。
- 玩家可在主教练页面签约、续约设置、强行解雇、查看近五场正式比赛战绩、管理卡库和回收卡片。
- 正式签约或解雇任一教练时生成全服公告。

## 加成方向

- 教练可增强特定打法、特定俱乐部球员等能力；等级越高，加成越强。
- 上线初版使用保守加成，具体数值以后根据比赛数据和经济数据平衡。
- 60 人现代豪门教练目录及加成明细以产品表格为准，卡画由后台工作台上传。

## 后续实现边界

- 主教练前台页面、教练卡包、唯一所有权、合同结算、交易市场、公告和后台卡画工作台作为独立版本实现。
- 主开发线暂不启用教练导航、API、比赛结算和体力加成逻辑。
