# V2.1 战术适配说明书

本文对应当前 V2.1 空间模型、控球链、动态站位和球员职责实现。战术效果不是单独由一个总评字段决定，而是由阵型位置、球员角色、能力组合、战术参数和比赛阶段共同计算。

## 一、适配规则总览

### 1. 球员能力先转换为执行指标

引擎会把 26 项球员能力转换为以下执行指标：

| 执行指标 | 主要参考属性 | 主要用途 |
| --- | --- | --- |
| 出球组织 `buildUp` | 传球、视野、决策、第一脚、镇定 | 后场和中场出球、控球链建立 |
| 推进 `progression` | 传球、视野、盘带、决策、速度、加速 | 从后场进入中场和前场 |
| 抗压 `pressResistance` | 第一脚、盘带、镇定、决策、力量、敏捷 | 被压迫时保有球权 |
| 防守对抗 `defensiveDuel` | 抢断、位置、盯人、速度、力量、决策 | 抢断、封堵和区域防守 |
| 机会创造 `chanceCreation` | 传球、视野、决策、传中、盘带、镇定 | 传威胁球、制造机会、边路进攻 |
| 无球移动 `movement` | 跑位、加速、速度、决策、敏捷、镇定 | 前插、拉扯、反击跑位 |
| 终结 `finishing` | 射门、镇定、跑位、第一脚、决策 | 常规射门和机会转化 |
| 空中终结 `aerialFinishing` | 头球、弹跳、力量、跑位、镇定 | 传中、角球和长传冲吊头球 |
| 远射 `longShot` | 远射、镇定、射门、第一脚、决策 | 中场真空和低位防守下的远射 |
| 射门预防 `shotPrevention` | 位置、盯人、决策、速度、力量、弹跳 | 限制射门质量和禁区防守 |
| 门将扑救 `goalkeeping` | 门将、反应、位置、镇定 | 扑救和低位防守最后一道防线 |
| 压迫 `pressing` | 体能、工作投入、速度、抢断、侵略性、决策、力量 | 高压、反抢和防守施压 |
| 纪律 `discipline` | 纪律、决策、抢断、镇定、侵略性 | 犯规、牌和伐木风险控制 |

球员的体能、位置适配度、职责和特性会对上述指标继续修正。

### 2. 适配倍率有上限

打法适配度统一限制在 `0.82 - 1.18`。因此：

- 球员非常适合某打法时，最多获得约 18% 的打法适配增益。
- 球员不适合某打法时，最多承受约 18% 的适配损失。
- 适配度不会替代阵型结构；极端阵型仍会产生中场真空、纵向脱节和后场暴露。

### 3. 位置不是名义位置，而是实际站位

引擎按照球员在战术板上的实际坐标推断 `GK/DEF/MID/ATT` 和具体职责。球员的 `LW/RW/LB/RB/DM/CB` 等角色会同时影响：

- 所在区域的占位、控制和支援；
- 该区域的压迫和防守覆盖；
- 与附近球员的连接质量；
- 中场人数、中央覆盖和纵向间距；
- 动态阶段中的前插和回收。

## 二、七种核心打法

## 1. 两翼齐飞 `wingPlay`

### 核心思路

通过 LW/RW 或 LM/RM 拉开宽度，由边锋、边前卫和 LB/RB/LWB/RWB 共同制造边路人数和传中机会。

### 重点参考球员

| 位置 | 重点能力 |
| --- | --- |
| LW/RW | 机会创造、跑位、推进、速度、加速、传中、盘带、终结 |
| LM/RM | 机会创造、跑位、传中、推进、体能、压迫 |
| LB/RB | 机会创造、推进、传中、速度、体能、支援能力 |
| LWB/RWB | 机会创造、推进、传中、跑位、体能、速度 |
| ST | 跑位、头球、力量、终结、镇定 |

当前打法适配度主要由以下组合构成：

- 边锋/边前卫机会创造：约 42%；
- 边锋/边前卫跑位：约 20%；
- 边后卫机会创造和传中能力：约 25%；
- 宽区域球员推进：约 13%。

### 推荐站位

- `4-3-3`：LW/RW 保持高位宽站位，LB/RB 提供后插上。
- `3-4-3`：LM/RM 或翼卫提供持续边路宽度，三中卫负责保护转换。
- `5-2-3`：LWB/RWB 是主要宽度来源，但双后腰必须能保护中路。
- `4-4-2`：LM/RM 负责边路推进，两个 ST 争抢传中落点。

### 主要收益

- 边路区域占位和控制提高；
- 边路推进和传中收益提高；
- 边锋、边后卫的进攻影响会被具体角色修正；
- 宽度足够时可以拉开对手密集防守。

### 主要风险

- 两名边后卫同时前压会增加转换防守风险；
- 中路人数不足时，球队容易失去二点球和中场控制；
- 只有边锋而没有合格边后卫时，边路收益有限。

## 2. 密集短传 `possession`

### 核心思路

通过后场和中场连续传递保持球权，降低直接度，依靠抗压和位置支援控制比赛节奏。

### 重点参考球员

| 位置 | 重点能力 |
| --- | --- |
| CB/LB/RB | 传球、视野、决策、第一脚、镇定、抗压 |
| DM/CM | 传球、视野、决策、第一脚、盘带、镇定、体能 |
| AM | 传球、视野、决策、第一脚、跑位、机会创造 |
| 全体中后场 | 抢断、位置、盯人、决策，用于丢球后的防守保护 |

当前适配度主要由以下组合构成：

- 中后场出球组织：约 48%；
- 中后场抗压：约 27%；
- 防守单元的防守对抗：约 25%。

### 推荐站位

- 至少保持 3 名实际中场球员，最好有 1 名 DM 或稳定的中央 CM；
- `4-3-3`、`4-2-3-1`、`4-1-4-1` 适合维持中路连接；
- 后卫线与中场线不要出现过大的纵向间距；
- AM 可以前插，但必须保留 DM 或后场出球点。

### 主要收益

- 低直接度提高球权保持；
- 中场控制、连接质量和抗压能力提高；
- 中后场球员的传球能力同时改善进攻组织和失球后的防守稳定性；
- 防守对抗较强时，控球球队不容易因为一次丢球直接崩盘。

### 主要风险

- 中场人数不足会降低控球链成功率；
- 后场传球能力不足时，高压对手会直接破坏出球；
- 过度压上会带来高位防线身后空间。

## 3. 长传冲吊 `longBall`

### 核心思路

后场快速把球送到前场，利用中前场高度、头球和二点球争抢减少中场传递。

### 重点参考球员

| 位置 | 重点能力 |
| --- | --- |
| CB/DM | 传球、视野、决策、力量、长传执行能力 |
| ST | 头球、弹跳、力量、跑位、镇定、终结 |
| LW/RW/LM/RM | 头球、跑位、速度、力量、第二落点处理 |
| AM | 跑位、机会创造、第一脚、抗压、二点球连接 |

当前适配度主要由以下组合构成：

- 后场和后腰出球组织：约 42%；
- 中前场空中终结：约 46%；
- 中前场跑位：约 12%。

### 推荐站位

- `4-4-2`：双 ST 提供直接争顶和第二落点；
- `4-2-3-1`：ST 争顶，AM 和两翼争抢落点；
- `5-3-2`：三中卫出球，双前锋直接冲击；
- 后场至少需要一名传球和决策较好的 CB/DM。

### 主要收益

- 直接推进更容易跨过中场进入前场或禁区；
- 合格前锋的头球进球能力明显提高；
- 传中、角球和直接球的空中对抗会参考身高、头球、弹跳和力量；
- 面对高位压迫时，可以绕过第一道压迫线。

### 主要风险

- 前场没有高度和空中能力时，长传会变成无效丢球；
- 后场出球质量不足时，直接球的落点和连接质量下降；
- 中场人数少会降低第二落点控制。

## 4. 伐木/粗野打法 `roughPlay`

### 核心思路

用高强度身体对抗、侵略性抢断和区域压迫破坏对手推进。

### 重点参考球员

| 位置 | 重点能力 |
| --- | --- |
| CB/LB/RB | 抢断、盯人、位置、力量、速度、决策 |
| DM/CM | 抢断、位置、体能、侵略性、力量、压迫 |
| 全体防守单元 | 防守对抗、射门预防、压迫 |
| 重点纪律控制 | 纪律、决策、镇定，降低无谓犯规和牌 |

当前适配度主要由以下组合构成：

- 防守单元防守对抗：约 56%；
- 防守单元压迫：约 44%。

### 推荐站位

- `4-1-4-1`、`4-5-1`、`5-3-2` 适合在中场和边路形成多人对抗；
- DM 应位于中卫前方，承担第一道拦截；
- 不建议所有球员同时离开防守区域追抢。

### 主要收益

- 防守对抗和压迫收益大幅提高；
- 对手在中场和推进阶段更容易被迫失误；
- 防守能力强的球队可以把身体对抗转化为球权回收。

### 主要风险

- 犯规、黄牌、直接红牌和伤病风险提高；
- 侵略性高但决策和纪律低的球员容易造成禁区附近危险定位球；
- 过度前压会暴露身后空间。

## 5. 防守反击 `counterAttack`

### 核心思路

先通过防守对抗或压迫赢回球权，再利用前场速度、跑位和终结快速完成转换。

### 重点参考球员

| 位置 | 重点能力 |
| --- | --- |
| CB/DM/后场 | 防守对抗、抢断、盯人、位置、传球、视野、决策 |
| LW/RW/LM/RM | 跑位、速度、加速、抗压、推进 |
| ST | 跑位、速度、加速、抗压、终结、镇定 |
| AM | 第一脚、视野、决策、推进、跑位 |

当前适配度主要由以下组合构成：

- 后场防守对抗：约 28%；
- 后场出球组织：约 25%；
- 前场跑位：约 20%；
- 前场抗压：约 15%；
- 前场终结：约 12%。

### 推荐站位

- `4-2-3-1`：双 DM 保护后场，三名前场球员负责第一时间冲刺；
- `5-3-2`：三中卫和三中场保护防区，双 ST 直接冲击；
- `4-4-2`：防守阵型紧凑，双前锋提供两个反击出口；
- 防守线不宜过高，前场必须保留至少一个速度型出口。

### 主要收益

- 断球后可以从事件区域直接启动反击；
- 反击推进、连接质量和反击射门 xG 根据球员适配度修正；
- 前场抗压高时，反击更不容易在第一脚传递中结束。

### 主要风险

- 后场出球差会导致断球后再次丢球；
- 前锋跑位和速度不足时，反击无法形成纵深；
- 过度退守会降低主动控球和常规进攻能力。

## 6. 高位压迫 `highPress`

### 核心思路

前场主动压迫后卫和中场，争取在对手前场或中场直接恢复球权。

### 重点参考球员

| 位置 | 重点能力 |
| --- | --- |
| ST/LW/RW/AM | 体能、工作投入、速度、抢断、侵略性、决策、力量 |
| DM/CM | 体能、工作投入、压迫、抢断、位置、决策 |
| CB/LB/RB | 抢断、位置、盯人、速度、射门预防、回追 |
| GK | 位置和出击覆盖，用于高防线身后保护 |

当前适配度主要由以下组合构成：

- 前场压迫：约 42%；
- 后场压迫：约 25%；
- 后场射门预防：约 18%；
- 后场防守对抗：约 15%。

### 推荐站位

- 防线整体前移，前后线间距要小；
- `4-3-3`、`4-2-3-1`、`3-4-3` 适合形成第一道和第二道压迫；
- 后场至少保留 3 名具备回追能力的防守球员；
- 门将出击和防线高度必须匹配。

### 主要收益

- 前场和中场区域压力提高；
- 推进阶段可以获得高压恢复奖励；
- 对手出球能力低时，容易在危险区域形成二次进攻。

### 主要风险

- 高防线会增加身后空间和被反击风险；
- 体能、工作投入或速度不足时，高压后段会失效；
- 后卫抢断和回追能力不足时，压迫越积极，暴露越明显。

## 7. 摆大巴/低位防守 `lowBlock`

### 核心思路

主动回收防线和中场，压缩禁区前沿及中央通道，优先限制对手射门质量，再寻找少量反击出口。

### 重点参考球员

| 位置 | 重点能力 |
| --- | --- |
| CB/LB/RB/LWB/RWB | 射门预防、位置、盯人、抢断、力量、速度 |
| DM/CM | 防守对抗、位置、盯人、拦截、力量 |
| GK | 门将、反应、位置、镇定 |
| ST/LW/RW | 抗压、跑位、速度、力量，用于反击出口 |

当前适配度主要由以下组合构成：

- 防守单元射门预防：约 44%；
- 防守单元防守对抗：约 30%；
- 门将扑救：约 14%；
- 前场抗压：约 12%。

### 推荐站位

- `5-4-1`、`5-3-2`、`4-5-1` 适合保护禁区和中央区域；
- 防线保持较低位置，后卫与中场纵向间距要小；
- 低位不等于所有球员堆在禁区，仍需保留至少一个反击出口；
- 面对边路球队时需要合格的边后卫或翼卫覆盖。

### 主要收益

- 防守三区占位增加；
- 对手进入禁区和完成高质量射门的难度提高；
- 门将能力直接影响低位防守的最终失球；
- 前场抗压高时，低位防守不会完全失去反击威胁。

### 主要风险

- 主动进攻、控球和推进能力下降；
- 长时间退守会增加远射、传中和二点球压力；
- 没有速度或抗压出口时，球队可能无法离开防守三区。

## 三、比赛思路与核心打法的区别

### 比赛思路

比赛思路主要改变整体意图和连续参数：

- `allOutAttack`：高心态、高节奏、高防线、高压迫，进攻承诺最高，结构暴露也最高。
- `positive`：主动进攻但保留一定结构。
- `balanced`：不对某一专属打法施加强绑定，使用通用能力和阵型模型。
- `defensive`：降低进攻承诺，提升紧凑度和反击倾向。
- `parkBus`：最低进攻承诺、低防线、高紧凑度和高时间消耗。

### 核心打法

核心打法决定球员属性适配和主要收益方向。比如：

- `positive + wingPlay`：主动利用边路创造机会；
- `balanced + possession`：以稳定控球为主；
- `defensive + counterAttack`：先防守再转换；
- `parkBus + lowBlock`：优先限制射门并保留反击出口。

同一核心打法在不同比赛思路下，收益和风险不会相同。

## 四、详细指令对适配的影响

### 持球指令

- `shortPassing`：降低直接度，强调中后场传球、抗压和控制。
- `vertical`：提高推进速度和纵向连接，对跑位、速度和决策要求更高。
- `wideOverload`：提高边路人数和边路连接，对边锋、边后卫机会创造要求更高。
- `centralCombination`：提高中央连接，对 DM/CM/AM 的传球、视野和决策要求更高。
- `longBall`：提高直接度，对后场传球以及前场空中终结要求更高。

### 无球指令

- `highPress`：提高压迫强度和防线高度，对体能、工作投入、速度、抢断和回追要求更高。
- `midBlock`：在中场区域保持压迫和结构的折中方案。
- `lowBlock`：回收防线和压缩空间，对位置、盯人、射门预防和门将要求更高。
- `zonal`：更依赖区域站位和防守覆盖。
- `manMark`：更依赖一对一防守、速度、盯人和决策。

## 五、阵型和站位的结构规则

### 中场完整性

引擎会统计实际位于中场带的球员数量、中央中场人数和最大纵向间距：

- 中场人数少于约 3 人会降低中场完整性；
- 中央区域无人会产生中央真空；
- 纵向间距过大时，推进连接和回防连接都会下降；
- 中场真空会增加对手远射决定概率和远射 xG。

### 后场暴露

以下情况会增加后场暴露：

- 后卫人数不足 3 人；
- 防线过高且门将与后卫距离过大；
- 中场和后卫纵向脱节；
- 高心态、高压迫和高防线同时使用；
- 三后卫体系中堆叠过多 AM；
- 边后卫同时前插但没有后腰保护。

### 动态阶段移动

球员会按比赛阶段发生位置前移：

- 构建阶段：LB/RB、DM 小幅前移，AM 提供连接；
- 推进阶段：边锋、LM/RM 和 AM 进一步前插；
- 前场阶段：AM、边路球员和 ST 进入更高威胁区域；
- 射门阶段：进攻球员提高禁区参与，后场保护仍受阵型和职责限制。

## 六、如何判断一支球队是否适合某打法

建议按以下顺序检查：

1. 先看阵型是否提供所需的实际位置，例如两翼齐飞需要边路球员，密集短传需要足够中场。
2. 再看核心位置的能力，而不是只看全队平均总评。
3. 检查站位是否造成中场真空、中央空缺或后场暴露。
4. 检查比赛思路是否和核心打法一致。
5. 最后看详细持球、无球指令和球员职责是否进一步强化或抵消打法。

全队总评高但关键位置能力错配，仍可能低于一支总评略低但结构合理的球队。

## 七、当前适配倍率上限

| 打法 | 主要收益上限 |
| --- | --- |
| 两翼齐飞 | 边路进攻约 12%，传中约 16% |
| 密集短传 | 控制约 10%，防守约 7.5% |
| 长传冲吊 | 推进约 10%，头球 xG 约 18% |
| 伐木 | 防守约 16%，压迫约 12% |
| 防守反击 | 转换约 16%，反击出口约 14% |
| 高位压迫 | 压迫约 14%，恢复球权约 10% |
| 摆大巴 | 防守约 16%，反击出口约 10% |

这些是适配倍率的最大边界，不是每场固定增加的数值。最终表现还会受到对手区域控制、天气、裁判、体能、比赛状态、阵型结构和随机事件影响。
