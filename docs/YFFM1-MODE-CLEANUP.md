# YFFM1 模式清理 · 2026-11-10

YFFM1 继续使用原 S4 的十一人制足球经营、联赛、杯赛、总决赛、友谊赛和单次 AI/镜像等现有玩法。本轮清理七人制 Roguelite 原型及其独立开发工具。

## 已移除

- `game/public/`：七人制页面、征程、选秀、商店、赛后成长、存档管理及专用资源。
- 旧场边实验室页面和数据库管理/七人制模拟代码，以及克隆仓库中随附的两份实验室数据库；当前游戏的账号和联赛存档路径继续沿用。
- `/game`、`/game/`、`/game/public/`、`/src/` 静态入口，以及旧 `/api/state`、`/api/reset`、`/api/simulate`、`/api/versus-traits` 接口。公开和本地开发模式均返回 404。
- 七人制模拟、特性抽卡演示命令和七人制专属测试；原型传奇保底、十场使用限制等专用逻辑也随原型移除。
- 根目录中未被当前程序引用的 S4 JS/CSS 源码与旧测试副本；对应历史版本可从 Git 查看。

## 当前共享边界

`shared/football/` 保存当前引擎和内容工具继续使用的属性规范、特性运行规则、环境配置与传奇球员资料。所有消费者已迁移导入路径，主模式不再依赖七人制目录。

`src/traits.js`、`src/new-trait-batch.js` 继续提供当前卡池的来源定义，`src/random.js` 继续提供随机数工具。V1/V2 比赛代码用于现有玩法、预测、历史战报和 V3 共享计算，继续保留。Rougelite 盾形卡框和开包素材已用于当前游戏，继续保留其来源记录和素材。

本轮未扩展到永久废弃的世界杯/主教练残留、隐藏的批量模拟实现或历史文档清理。

## 入口与构建

- `/` 在公开及本地模式中均跳转至 `/versus/`；后台仍为 `/admin/`。
- `npm start`、`npm run dev`、`npm run demo`、`npm run devtool` 均启动 `server.mjs`。
- `npm run build` 输出 `versus/dist/` 和 `admin/dist/`。
- 构建从仓库收录的 WebP 资源同步头像，原始 PNG 可选；缺失所需 WebP 仍会报错。单独运行 A 级及传奇头像同步命令时继续检查原图。
- Windows 离线打包收集 `shared/`，不再收集七人制目录。实际安装包仍需对应私有种子资料与打包后验收。
