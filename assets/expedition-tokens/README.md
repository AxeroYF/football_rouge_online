## 视觉规范

- 透明方形 PNG，源文件尺寸 `1254 × 1254`。
- 无人物、头像、肢体、队徽、品牌和文字。
- 球衣正面使用大号码，保证地图缩放后的辨识度。
- 六边形底座跟随球衣主色，不使用霓虹、发光或统一蓝色亮条。
- 地图正式显示尺寸建议为 `56–80px`；选中、行军和状态效果应由前端叠加，不写入原图。

## 生成规范摘要

使用内置图像生成模式逐张生成；统一提示结构为：简洁几何战棋图标、等距三分之四视角、球衣战术牌、同结构六边形底座、主色跟随国家队球衣、真实透明背景，并严格排除人物、徽章、品牌、场景和发光条。
